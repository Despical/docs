## Requirements

- **Java 21 or newer**, also meeting the server's own Java requirement.
- **Spigot or Paper** with traditional Bukkit scheduling. Folia is not supported.
- An authorized binary from [Hub](https://hub.despical.dev/plugins/carousel), [SpigotMC](https://www.spigotmc.org/resources/carousel.116224/) or [BuiltByBit](https://builtbybit.com/resources/carousel.50204/).

The build compiles against Paper **1.16.5**. Its `api-version: 1.13` metadata and compatibility helpers do not establish a tested range from Minecraft 1.8 through future versions. Validate the exact server release, especially mounted movement and leashes.

## Installation

<Steps>

1. Stop the server and place the authorized `carousel-2.0.4.jar` in `plugins/`.
2. Start the server and check the console for initialization errors.
3. Review `plugins/Carousel/config.yml`, `messages.yml` and `data.yml`.
4. As an operator in game, run `/carousel create spawn`, followed by `/carousel edit spawn`.

</Steps>

New rides start immediately and save their settings. Valid saved rides start again on enable or `/carousel reload`. Back up data and worlds before migrations.

## Optional Plugins

**PlaceholderAPI** expands player message tokens when installed. World-manager soft dependencies establish load ordering for their worlds. WorldGuard is declared as a soft dependency, but there is no region-protection hook; protect administration with permissions.

<Aside type="note" title="Administration">
Most commands require an in-game player. Only the root command, help and reload also accept the console. Administrative nodes default to operators; riding is open unless a custom riding permission is configured.
</Aside>
