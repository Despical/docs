## Command Reference

All administrative nodes default to operators. The root command needs no permission; `carousel.admin` adds its help prompt.

| Command | Permission | Audience | Result |
| --- | --- | --- | --- |
| `/carousel` | None | Player / console | Plugin name and version. |
| `/carousel help` | `carousel.help` | Player / console | Permitted commands, hover details and suggestions. |
| `/carousel create <id>` | `carousel.create` | Player | Create and start a saved ride at your location. |
| `/carousel edit <id>` | `carousel.edit` | Player | Open the inventory editor. |
| `/carousel start <id>` | `carousel.start` | Player | Start a stopped ride. |
| `/carousel list` | `carousel.list` | Player | Saved IDs with editor/teleport suggestions. |
| `/carousel teleport <id>` | `carousel.teleport` | Player | Teleport to the saved center. |
| `/carousel destroy <id>` | `carousel.destroy` | Player | Remove entities; keep saved settings. |
| `/carousel delete <id>` | `carousel.delete` | Player | Remove entities and saved settings. |
| `/carousel setting <id> <setting> <value>` | `carousel.setting` | Player | Save a numeric setting and restart a running ride. |
| `/carousel purge` | `carousel.purge` | Player | Remove tagged entities in loaded worlds. |
| `/carousel reload` | `carousel.reload` | Player / console | Reload settings/messages and restart saved rides. |
| `/carousel version` | `carousel.version` | Player | Plugin, server, Java, JVM and OS information. |

Help filters command permissions. Console help labels player-only actions. Clicking a row suggests a command without executing it.

## Additional Permissions

| Permission | Meaning |
| --- | --- |
| `carousel.*` | Grants all registered Carousel nodes. |
| `carousel.admin` | Shows the root-command help prompt. |
| `carousel.tabcompleter` | Enables command, ID and setting suggestions. |
| `carousel.setlocation` | Allows the Set Carousel Location button; editor access is also required. |

The custom riding node comes from `riding-horse-permission`. Empty means no extra riding permission, subject to the ride's settings, saddle compatibility and API event handlers.

Numeric names are case-sensitive: `ticks`, `degreeIncrease`, `radius`, `stepHeight` and `maxHeight`. See [movement](/carousel/mechanics/carousel-behavior/) for defaults and input boundaries.

## Cleanup and Saved State

`destroy` is temporary: saved rides return on enable/reload. `delete` removes the entry permanently. `purge` removes **all** matching tagged entities, including active rides; it does not delete saved settings or rebuild entities. Use `/carousel reload` afterwards.

Review diagnostics for private server information before sharing them.
