## Carousel

**Carousel** creates circular horse rides for hubs and theme parks. Save multiple centers, change horse count and appearance in an inventory editor, and tune rotation, radius and vertical movement with commands.

This guide describes **Carousel 2.0.4**. It requires **Java 21 or newer**, uses traditional Spigot/Paper scheduling and compiles against **Paper 1.16.5's API**. A compile API is not a tested server-version matrix; exact releases and reflection-based passenger movement need runtime validation. Folia is not supported.
