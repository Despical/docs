## Which versions can I use?

The bytecode target is **Java 21** and the compile API is **Paper 1.16.5**. The implementation uses traditional Bukkit scheduling and Spigot/Paper compatibility helpers. The `api-version: 1.13` descriptor and reflection fallbacks do not prove compatibility with every older or future release. Test exact server versions in game, including mounted movement. Folia is not supported.

## Why can a player not ride?

Check Allow Horse Riding, `riding-horse-permission` and plugins cancelling `CarouselMountEvent`. On Minecraft 1.20.5 and later, disable saddles: Carousel blocks mounting while they are enabled. Interactions while holding saddles or horse armor are also blocked.

## Why are inventory clicks blocked?

The inventory setting controls opening the horse inventory. Carousel independently cancels inventory clicks while mounted, even if opening the horse inventory is allowed.

## Why did a stopped ride return?

`destroy` removes entities but keeps settings. Saved rides start on enable/reload. Use `delete` to remove the saved entry.

## Why did entities disappear after purge?

Cleanup matches the exact invisible custom name `§8§8§0§c§d` after color normalization. Do not apply it to unrelated entities. Purge includes active rides; run `/carousel reload` to recreate saved entities. It scans loaded-world entities without loading every chunk.

## Why was a ride skipped?

Check warnings for invalid locations or unavailable worlds. Restore/load the world, retain the complete settings and reload. World-manager soft dependencies provide load ordering, not a guarantee that every world is available.

## Why is movement uneven?

TPS, update interval, extreme angular/vertical steps and server mappings affect movement. Internal position updates fall back to teleportation when unavailable, potentially changing passenger smoothness. Test default settings and report exact server/Java versions.

## Are there particles or region hooks?

There is no configurable particle feature or WorldGuard protection hook. Command permissions protect administration; settings, a custom riding node and cancellable events control rider access.

## Why did reload fail?

Repair malformed YAML or non-text message values using the console error. Message validation happens before rides restart. Keep configuration, saved data and world backups.
