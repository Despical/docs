Maze Engine presents its controls in Minecraft chat. These images show actual panels captured in-game with earlier chat cleared between commands. Each gallery groups related screens; use its arrows, swipe, or select an image to enlarge it.

Open chat to interact with the buttons. Hover a command, row or field for additional details. Available actions depend on your permissions and the maze's current state.

## Command Help

Run `/maze help` to browse commands for building, previewing and exploring, then switch to page 2 for management. Clicking a command fills the input so you can complete its arguments before submitting it.

<ScreenshotGallery label="Command help pages" images={commandHelpScreenshots} />

The help cards explain **create**, **teleport**, **setspawn**, **regenerate** and **cancel**. This gallery pairs each hovered panel with its focused tooltip, preserving the exact wording shown in Minecraft.

<ScreenshotGallery label="Command hover explanations" images={commandHoverScreenshots} />

See the [command reference](/maze-engine/commands/) for all arguments, options and permissions.

## Concept Explanations

`/maze help concepts` covers seeds and complexity, cells and geometry, presets and connections, placement and snapshots, and selections and origin. Tall cards have separate heading and lower views; scroll in chat to read both parts of a card.

<ScreenshotGallery label="All five concept pages with heading and lower views" images={conceptHelpScreenshots} />

The [core concepts guide](/maze-engine/concepts/) expands these terms with sizing examples and links to their settings.

## Preset Browser

`/maze presets` lists themes with their configured difficulty, path width and wall height. Previous and Next navigate the three captured pages. Clicking a theme suggests a preview command.

<ScreenshotGallery label="All preset browser pages" images={presetBrowserScreenshots} />

Hover cards describe the selected theme and its generation settings. Bamboo, Default and Abyss illustrate the range from broad open routes to narrow roofed corridors. Each panel is followed by its matching tooltip crop.

<ScreenshotGallery label="Bamboo, Default and Abyss preset hover cards" images={presetHoverScreenshots} />

These values come from editable preset files. See [presets](/maze-engine/presets/) to customize them and the [preset gallery](/maze-engine/preset-gallery/) to compare their built geometry.

## Saved Maze List

`/maze list` displays saved mazes with their theme, cell dimensions and current status. Hover a row for a summary or click it to open its management panel.

## Maze Details and Actions

`/maze info <name>` displays saved geometry, world position, graph statistics, seed, snapshot availability and teleport destination. The gallery includes ready Hedge, Sakura and Frost examples, a custom arrival point, and other saved records. The Hedge heading and lower action view are separate captures of the same panel.

<ScreenshotGallery label="Saved maze details and actions" images={mazeDetailsScreenshots} />

**Teleport** moves you to the destination, **Guide** enables personal route arrows, and **Copy seed** copies the generation seed. **Repair** restores planned non-air structure; **Delete** opens a removal review. Read [operations and recovery](/maze-engine/operations-and-recovery/) before choosing an action that changes blocks.

Hover **Snapshot**, **Entrance**, **Copy seed** or a custom arrival point for the meaning of that value. The next gallery pairs every hovered field with its focused tooltip.

<ScreenshotGallery label="Snapshot, entrance, seed and custom-arrival explanations" images={mazeDetailsHoverScreenshots} />

## Preview Confirmation

After a preview finishes planning, its panel summarizes the retained specification. These examples compare an open Hedge preview with a roofed Dungeon preview. Move outside the target volume, then choose **Create** to submit the shown specification for construction. **Close** ends the preview.

<ScreenshotGallery label="Open and roofed preview confirmation panels" images={previewScreenshots} />

`/maze preview stop` closes an active session. The captured feedback also shows a repeated stop request when no preview remains, and closure of the roofed preview.

<ScreenshotGallery label="Preview closure and inactive-session feedback" images={previewLifecycleScreenshots} />

## Route Guide

`/maze solve <name>` enables personal arrows toward the exit and provides **Close guide**. Enter the corridors to follow the arrows; enabling a guide does not teleport you. The captured sequence shows enabling it, requesting the same active guide again, closing it, and requesting closure when none remains.

<ScreenshotGallery label="Personal route guide lifecycle" images={guideLifecycleScreenshots} />

See [previews and route guides](/maze-engine/previews-and-guides/) for session lifetimes, permissions and visual settings.

## Removal Review and Request Lifetime

`/maze delete <name>` opens a review stating the terrain policy before confirmation. The example has no snapshot, so its policy clears the saved volume. **Cancel** closes that review; the final captured message confirms the request was cancelled.

<ScreenshotGallery label="Clear-removal review, Cancel hover and cancelled request" images={removalReviewScreenshots} />

Buttons belong to a particular actor, record or visual session. An expired or unavailable request must be opened again; dismissing an already-closed request produces separate feedback.

<ScreenshotGallery label="Expired and already-closed request feedback" images={requestLifecycleScreenshots} />

## Settings and Validation Feedback

`/maze reload` validates the replacement settings, messages and presets before applying them. This capture shows a successful settings reload.

<ScreenshotGallery label="Settings reload feedback" images={settingsScreenshots} />

Validation panels identify an unknown maze, unknown preset, invalid help page, or a maze name that already exists. Correct the named argument and submit a fresh request.

<ScreenshotGallery label="Command validation examples" images={validationErrorScreenshots} />

See [troubleshooting](/maze-engine/misc/faq/) for the corresponding recovery steps. Customize panel wording and colors through [messages.yml](/maze-engine/configuration/messages/).
