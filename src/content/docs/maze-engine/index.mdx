## Maze Engine

**Maze Engine** builds persistent mazes directly in your Minecraft world. Choose a theme, preview its layout, and create a maze with a reproducible seed. Manage the finished structure through interactive chat panels, guide players to its exit, rebuild it, or restore the terrain captured before construction.

<GameScreenshot src="/images/mazeengine/presets/hedge-side.webp" alt="The Hedge preset viewed from the side in Minecraft, with leaf walls, grass corridors, flowering caps, and floor lighting" />

Compare all 30 themes in the [preset gallery](/maze-engine/preset-gallery/), or explore [previews and route guides](/maze-engine/previews-and-guides/) for in-game examples. Select any screenshot to enlarge it without leaving the documentation.

Maze Engine supports **Paper for Minecraft 1.21.11 and later** and requires **Java 25**. WorldEdit or FastAsyncWorldEdit, WorldGuard, and PlaceholderAPI are optional integrations.

## Themes and Generation

The plugin includes **30 editable presets**, from open hedge gardens and desert passages to roofed dungeons, copper halls, and volcanic corridors. Presets control physical geometry, block palettes, decorations, generation settings, and display metadata.

## Developer API

The public API exposes immutable maze descriptions, preset metadata, graph routes, operation handles, and completion events. Integrations use the same permission, ownership, and region checks as commands.
