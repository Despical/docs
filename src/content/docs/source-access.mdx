**[Despical's Plugin Hub](https://hub.despical.dev/)** keeps your premium plugin purchases, downloads, linked accounts, and eligible source repositories together. When source access is available for a plugin you own, the Hub grants your connected GitHub account access to its private repository.

<Aside type="note" title="Access depends on the plugin">
    A premium plugin purchase does not automatically guarantee a private repository. The **Source Access** page in the Hub is the current source of truth for eligibility and access status.
</Aside>

---

## Getting access

<Steps>
1. **Create your Plugin Hub account.** Sign in with Discord to create or access your customer account.
2. **Verify your purchase.** Link the Spigot profile that purchased your plugins. For a premium plugin purchased on BuiltByBit, [open a Hub support ticket](https://hub.despical.dev/tickets) so the purchase can be reviewed manually.
3. **Connect your GitHub account.** Choose the GitHub account that should receive private repository access.
4. **Wait for the access review.** Supported repositories will appear on your Hub Source Access page and become available through the connected GitHub account.
</Steps>

## Before opening a repository

Source access does not transfer ownership of a plugin, its source code, branding, or documentation. Your premium license remains personal, revocable, non-exclusive, and non-transferable.

- Keep your Plugin Hub, marketplace, and GitHub credentials private.
- Do not redistribute, leak, mirror, upload, gift, rent, resell, or sublicense the plugin, its source, or compiled builds.
- Do not remove copyright notices, bypass licensing controls, or present modified copies as your own product.
- Keep proof of purchase and protect any private backups or files downloaded from a repository.
- Give employees or contractors access only when it is necessary to operate servers you own or directly manage, and remain responsible for that access.

<Aside type="caution" title="The current EULA controls">
    This page is a practical access guide, not a replacement for the license agreement. Always review the current [Premium Plugin EULA](https://hub.despical.dev/premium-terms) before using a private repository.
</Aside>

## If access does not appear

Check the following before contacting support:

1. For a Spigot purchase, make sure the account linked in the Hub is the account that purchased the plugin.
2. For a BuiltByBit purchase, [open a Hub ticket](https://hub.despical.dev/tickets) and include the plugin name and the information needed to locate the purchase.
3. Confirm that the GitHub username shown in **Linked Accounts** is the account you intend to use.
4. Check the Hub's **Source Access** page for the plugin's eligibility and review status.
5. Allow time for the review and GitHub access to be applied.

If everything is correct and access is still missing, contact support with the plugin name and the marketplace account used for the purchase. Never send passwords, recovery codes, or private credentials.
