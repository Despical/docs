## Pixel Painter

**Pixel Painter** turns an image into a wall or floor made from Minecraft blocks. Choose its height and direction, compare material counts, then paint with perceptual color matching and optional dithering. Transparent pixels can preserve the terrain behind the image. Persistent undo journals keep original block properties available after cancellation or a server restart.

The plugin requires **Paper 1.21.11 or later** and **Java 25**. All command permissions default to operators. This guide describes **Pixel Painter 2.0.0**; older builds use different commands, sizing and undo behavior. Spigot and Folia are not supported.

## Colors and Terrain

The bundled palette contains **335 different materials**: concrete, wool, terracotta, logs, wood, ores, foliage, glass, stable ice, mushrooms and newer copper, cherry, bamboo, pale oak, resin and tuff families. Oklab matching chooses representative colors; Floyd-Steinberg dithering adds detail to gradients when enabled.

Painting runs one world job at a time with a configurable tick budget. The service validates build height, world borders, chunk count, journal capacity and region overlap, then saves its undo journal before placing any blocks.
