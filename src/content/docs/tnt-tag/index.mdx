## TNT Tag

**TNT Tag** turns the familiar game of tag into an explosive multiplayer minigame. At the start of each round, selected players receive TNT and must punch another player before the timer reaches zero. Whoever is still tagged when time expires is eliminated.

The plugin manages the complete match lifecycle, including arena setup, multiple tagged players, decreasing round timers, deathmatch, spectators, configurable power-ups, join signs, statistics, leaderboards, rewards, PlaceholderAPI integration, Bungee server mode, and a Bukkit event API.
