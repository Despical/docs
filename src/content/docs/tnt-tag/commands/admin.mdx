Admin Commands are designed for **server administrators and staff members** to manage **TNT Tag** games and plugin behavior.

All commands use `/tnttag`. Unless otherwise stated, all commands can also be executed from the console.

---

## Main Command

Displays the current **TNT Tag** version and author. Senders with the `tnttag.admin` permission are also directed to the help command.

```bash
/tnttag
```

---

## Force Start Command

Administrators with the `tnttag.admin.forcestart` permission can skip the waiting countdown for the arena they are currently in.

The command is only accessible to players and requires at least two joined players.

```bash
/tnttag forcestart
```

---

## Stop Command

Administrators with the `tnttag.admin.stop` permission can immediately stop the arena they are currently in.

The command is only accessible to players and resets the arena without treating the match as a naturally completed game.

```bash
/tnttag stop
```

---

## Reload Command

Administrators with the `tnttag.admin.reload` permission can reload the plugin's configuration files without restarting the server.

This command is only accessible to players.

```bash
/tnttag reload
```

---

## Version Command

Administrators with the `tnttag.admin.version` permission can display detailed information about the plugin, server, Java runtime, JVM, and operating system.

This command is only accessible to players.

```bash
/tnttag version
```

---

## Help Command

Administrators with the `tnttag.admin.help` permission can display a list of available commands and their descriptions.

```bash
/tnttag help
```

---

## Command Blocking Bypass

When command blocking is enabled, active players can only use allowed commands unless they have the `tnttag.command.override` permission.

```text
tnttag.command.override
```

---

## Join Sign Permissions

The current runtime checks the following permissions when a player creates or breaks an arena sign:

```text
tnttag.admin.sign.create
tnttag.admin.sign.break
```

<Aside type="caution">
    The declared `tnttag.admin.*` wildcard contains `tnttag.sign.create` and `tnttag.sign.break`, while the sign listener checks the `tnttag.admin.sign.*` names shown above. Grant the runtime names explicitly until this mismatch is corrected.
</Aside>

<Aside type="tip">
    For server administrators, granting the wildcard permission `tnttag.admin.*` will provide access to the administrative commands listed on this page and the arena commands.
</Aside>
