---
title: Player Commands
description: TNT Tag commands for joining, leaving, viewing statistics, and checking leaderboards.
---

Player Commands are available to **regular players** and do not require administrative permissions. These commands allow players to interact with **TNT Tag** gameplay by joining arenas, leaving matches, and viewing statistics.

All commands use `/tnttag`. The internal command fallback prefix is `ttag`.

---

## Join Command

Allows a player to join a **TNT Tag** arena. The plugin checks that the arena is ready and has an available slot before allowing the player to join.

No permission is required unless `Join-Permission` is configured in `config.yml`. If the match has already started, the joining player becomes a permanent spectator for that match.

```bash
/tnttag join <arena>
```

---

## Random Join Command

Selects an available arena automatically and joins it. This command is not available while Bungee mode is enabled.

```bash
/tnttag randomjoin
```

---

## Leave Command

Safely removes the player from their current **TNT Tag** arena.

```bash
/tnttag leave
```

---

## Stats Command

Displays stored **TNT Tag** statistics for yourself or the specified player, including wins, losses, games played, players tagged, and times tagged.

```bash
/tnttag stats [player]
```

---

## Top Command

Displays the leaderboard for a stored statistic. Valid values include `wins`, `loses`, `games_played`, `tagged_players`, and `times_tagged`.

This command can also be executed from the console.

```bash
/tnttag top <statistic>
```
