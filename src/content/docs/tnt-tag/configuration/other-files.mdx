## stats.yml

When `Database-Enabled` is false, player statistics are stored locally in `stats.yml`. TNT Tag periodically saves records according to `Statistic-Saving-Period`.

Do not edit this file while the server is running. Back it up before changing storage modes or moving the plugin to another server.

## Inventory Backups

With the inventory manager enabled, TNT Tag captures player state before placing a player in an arena and restores it on exit. Recovery data exists to reduce item loss after an interrupted match or restart.

Do not delete recovery data while players are inside an arena. If restoration fails, stop the server, preserve the TNT Tag folder, and collect the console error before attempting a manual repair.

## Regenerating Defaults

To obtain a fresh copy of a configuration file, stop the server, rename the existing file, and start the server once. Compare and migrate only the settings you intend to keep instead of replacing the entire plugin folder.
