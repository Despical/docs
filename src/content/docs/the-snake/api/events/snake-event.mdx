---
title: SnakeEvent
description: Base class for all public Bukkit events exposed by The Snake.
---

`SnakeEvent` extends Bukkit's `Event` class and is the common marker parent of every public event in the plugin. Each concrete event owns an independent Bukkit `HandlerList`.

## Technical Overview

* **Package:** `dev.despical.snake.api.event`
* **Parent Class:** `org.bukkit.event.Event`
* **Asynchronous:** No
* **Cancellable:** No

The base class contains no shared arena or player accessor because `KeyPressedEvent` and statistic-related events have different contexts. Use the methods on each concrete event.

Do not register `SnakeEvent` itself as a catch-all Bukkit listener. Register the concrete events needed by your integration. For generic discovery tooling, use `EventRegistry.getRegisteredTypes()` and resolve the class for each `EventType`.
