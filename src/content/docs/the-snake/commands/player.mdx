---
title: Player Commands
description: Player-facing commands for joining and leaving The Snake arenas.
---

The root command is `/snake`. Player commands are restricted to in-game players because the game requires a player inventory, location, and camera.

| Command | Permission | Description |
|:--|:--|:--|
| `/snake` | None | Displays no menu by itself, but validates the root command and reports unrecognized subcommands. |
| `/snake join <arena id>` | None | Attempts to join the specified ready and unoccupied arena. |
| `/snake leave` | None | Leaves the current arena, restores the inventory, and teleports to the end location. |

---

## Join Requirements

`/snake join <arena id>` succeeds only when:

* the arena exists;
* all required arena locations have been saved;
* the arena is marked ready;
* the player is not already in a Snake arena; and
* the target arena does not already have a player.

An arena accepts one player at a time.

---

## Leaving Safely

Use `/snake leave` instead of removing the player with another plugin. The normal leave flow restores potion effects, inventory data, board blocks, statistics, the invisible camera vehicle, and arena availability.
