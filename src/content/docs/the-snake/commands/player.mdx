---
title: Player Commands
description: Player-facing commands for joining and leaving The Snake arenas.
---

Player Commands are available to **regular players** and do not require administrative permissions. These commands allow players to interact with **The Snake** gameplay by joining and leaving arenas.

All commands use `/snake`. The internal command fallback prefix is `thesnake`.

---

## Main Command

The main command validates the root command and reports unrecognized subcommands. When executed without arguments, it does not open a menu.

```bash
/snake
```

---

## Join Command

Allows a player to join a **The Snake** arena. The target arena must exist, be completely configured, be marked as ready, and not already contain another player.

An arena accepts one player at a time.

```bash
/snake join <arena_id>
```

---

## Leave Command

Safely removes the player from the current arena, restores their inventory and potion effects, removes the camera vehicle, resets the board, and teleports them to the configured end location.

```bash
/snake leave
```
