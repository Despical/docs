Arena management commands allow administrators to build and maintain the game environments. These commands are essential for the initial setup and ongoing management of your **The Snake** maps.

---

## Create Command

Administrators with the `snake.arena.create` permission can register a new arena instance.

Arena IDs must be unique when compared case-insensitively, contain 1-64 characters, and cannot contain spaces or periods. Use `/snake edit <arena_id>` after creation to begin setup.

```bash
/snake create <arena_id>
```

---

## Delete Command

Administrators with the `snake.arena.delete` permission can permanently remove an arena instance from `arenas.yml`. The first command displays a confirmation prompt. Confirming also stops an active game and safely exits an active editor session.

```bash
/snake delete <arena_id> [--confirm] [--cancel]
```

---

## Edit Command

Administrators with the `snake.arena.edit` permission can load the editor items for an existing arena.

Editing is blocked while another player is editing the same arena. This command is only accessible to players because the editor depends on the sender's position, inventory, and block interactions.

Running the command for the arena you are already editing stops the editor. Editing is also blocked while you are playing, while the arena has an active game, or while you are editing another arena.

```bash
/snake edit <arena_id>
```

---

## List Command

Administrators with `snake.arena.list` can display every registered arena and its readiness state. Ready arena IDs can be clicked to join; incomplete arena IDs can be clicked to edit.

```bash
/snake list
```

<Aside type="tip">
    For server administrators, granting the wildcard permission `snake.*` will provide access to every command listed on this page and command tab completion.
</Aside>
