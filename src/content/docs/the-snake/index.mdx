## The Snake

**The Snake** brings the classic Snake game into Minecraft. A player controls a block-based snake across a two-dimensional arena board, collects apples to score and grow, and tries to avoid hitting the snake's own body or an arena border.

Each arena is a separate single-player board with its own movement speed, win condition, wrap-around rule, block palette, start location, and exit location. The plugin also includes persistent statistics, leaderboards, PlaceholderAPI integration, flat-file or MySQL storage, and Bukkit events for custom integrations.
