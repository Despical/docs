## Editable configuration

`config.yml`, `messages.yml`, `menus.yml`, `rewards.yml`, `hunts/`, `templates/` and `particle/` are the current editable configuration. Missing defaults are installed without replacing existing files.

## Persistent data

SQLite uses `easter-eggs.db`; MySQL stores the corresponding `ee_*` tables in the configured database. Placements, player progress, discoveries, reward rights, delivery state, pending items and preferences are durable data. Do not edit these tables while the plugin is running.

Back up the configuration and database together. Stop the server before copying a SQLite installation. Preserve SQLite journal files if present.

## Legacy files

The 2.x `data/locations.yml`, `data/stats.yml` and `mysql.yml` are import sources, not active 3.0.0 configuration. Migration copies the source to a backup and writes `migration-report.txt`. Imported hunts remain disabled until reviewed.

See [operations and migration](/easter-eggs/operations/) before upgrading or restoring data.
