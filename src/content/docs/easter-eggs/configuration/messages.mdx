`plugins/EasterEggs/messages.yml` holds every chat message, panel title, clickable button, hover text, and help page. Inventory text is in [menus.yml](/easter-eggs/configuration/menus/). Apply changes with `/eggs admin reload`.

## Languages

Set `language` in `plugins/EasterEggs/config.yml` and run `/eggs admin reload`:

```yaml
language: tr
```

Regional forms such as `pt-BR`, `zh_SG`, `ms-MY`, and `ta-SG` resolve to their base language.

The language covers chat messages, panel titles, buttons, hovers, help pages, and the titles, labels, and descriptions in [menus.yml](/easter-eggs/configuration/menus/). Hunt names, template names, reward text, and hints are your own content and are shown as written.

### Customizing a Translation

On startup, missing bundled files are copied to `plugins/EasterEggs/languages/`. Edit `languages/<code>.yml` to change that translation, keeping its keys and placeholders, then reload. Keys are flat, for example `messages.found` or `menus.labels.start`.

Text you changed in `messages.yml` or `menus.yml` takes priority over the selected language. Values still equal to the bundled English default follow the translation, so an untouched `messages.yml` never blocks it. To translate a message you customized earlier, restore its default or edit it directly.

Keys missing from your copy fall back to the bundled translation, so plugin updates that add text keep working. Malformed YAML, a value that is not text, or an unknown language code rejects the reload and keeps the running configuration.

## Format

- Text uses [MiniMessage](https://docs.advntr.dev/minimessage/format.html): `<bold>`, `<#B8C2D4>`, gradients, and `<newline>`.
- A message can be a single string or a list of lines.
- An empty string or `[]` disables that message.
- **Missing keys inherit the bundled default**, so you can delete everything you do not change.
- Inside single-quoted YAML strings, write an apostrophe twice: `'hunt''s'`.
- Keep named placeholders such as `<hunt>`, `<found>`, and `<reason>` unchanged. Values are inserted as plain text and cannot inject formatting.

## Panels

Most messages are shown as a small panel: a separator line, a colored title, the body, and another separator.

```yaml
panel-separator: '<#394555><strikethrough>                                                                        </strikethrough></#394555>'
panel-title: '<#7FFFE1><bold>Easter Eggs</bold></#7FFFE1>'

found: '<#B8C2D4>Found <egg>!</#B8C2D4> <#B8C2D4>(<found>/<total>)</#B8C2D4>'

panel-titles:
  found: '<#76F5A4><bold>Egg Discovered</bold></#76F5A4>'
```

`panel-separator` can be set to `''` to hide the separator lines. `panel-title` is the fallback title; `panel-titles.<key>` sets the title for one message key.

## Message Groups

| Keys | Used for |
| --- | --- |
| `loading`, `error`, `no-permission`, `player-only`, `action-cancelled` | General feedback. `<reason>` in `error` explains the problem |
| `unknown-hunt`, `unknown-template`, `unknown-particle` | Invalid IDs |
| `inactive`, `requirements`, `empty-hunt` | Hunt closed, entry requirements not met, or no eggs placed |
| `found`, `complete`, `already-found`, `shared-taken`, `wrong-order` | Collection results |
| `start-required`, `started`, `already-started`, `free-exploration`, `left`, `no-active-attempt`, `failed`, `completed-before`, `cooldown` | Attempt lifecycle |
| `hint`, `hint-cooldown`, `no-hint` | Text hints |
| `hot`, `warm`, `cold` | Hot and cold action-bar feedback |
| `pending.reminder`, `pending.warning`, `pending.expired`, `pending.empty`, `pending.claimed`, `pending.full`, `pending.received` | Reward inbox |
| `schedule.opened`, `schedule.closed` | Broadcasts when a scheduled hunt opens or closes |
| `admin.*` | Editor and command feedback: prompts, placement results, reloads, resets, migration, and deliveries |

Common placeholders include `<hunt>`, `<egg>`, `<found>`, `<total>`, `<time>`, `<hint>`, `<count>`, `<template>`, `<preset>`, `<reason>`, and `<report>`, depending on the message.

## Buttons and Hovers

Clickable chat buttons and their hover texts:

```yaml
buttons:
  progress: '<#7ABFCC>[Progress]</#7ABFCC>'
  retry: '<#7ABFCC>[Start again]</#7ABFCC>'
  inbox: '<#7ABFCC>[Open rewards]</#7ABFCC>'

hovers:
  retry: '<#7ABFCC>Start a new eligible attempt.</#7ABFCC><newline><#B8C2D4>Existing earned rights are preserved.</#B8C2D4>'
```

Available buttons are `cancel-input`, `hunts`, `progress`, `retry`, `rewards`, `leaderboard`, `inbox`, `help`, `editor`, `previous`, `next`, and `disable-editor`. Each has a hover entry with the same name.

## Help Pages

`help` builds the interactive `/eggs help` and `/eggs admin help` pages.

```yaml
help:
  title: '<#DCE3EE><bold>Easter Eggs</bold></#DCE3EE>'
  description: '<#B8C2D4>Hover for details. Click to open or fill a command.</#B8C2D4>'
  row: '  <#606A7B>•</#606A7B> <command> <#606A7B>·</#606A7B> <#B8C2D4><description></#B8C2D4>'
  navigation: '<previous>  <#8792A6><page> / <pages></#8792A6>  <next>'
  player:
    hint:
      syntax: '/eggs hint [hunt]'
      description: 'Request a text hint'
      hover: '<#7FFFE1><bold>Need a Clue?</bold></#7FFFE1><newline>...'
```

`help.player.<command>` and `help.admin.<command>` set each command's displayed syntax, one-line description, and hover card. Only commands the reader has permission for are listed.
