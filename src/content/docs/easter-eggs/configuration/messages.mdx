`messages.yml` controls player feedback and interactive chat panels. Inventory titles and item text live separately in `menus.yml`.

## MiniMessage

Use MiniMessage tags such as `<gold>`, `<bold>` and hex colors. Quote YAML strings that contain markup. Dynamic tags such as `<hunt>`, `<found>`, `<total>` and `<time>` depend on the message being rendered; use the bundled comments for the supported values in each entry.

```yaml
found: '<#8BD5CA>You found an egg in <hunt>! <found>/<total></#8BD5CA>'
```

This illustrates message formatting; edit the corresponding existing message key in your generated file. Legacy numbered placeholders and old 2.x message sections are not the 3.0.0 schema.

## Help and prompts

Player help and administrator help have separate pages, command descriptions, hover text and clickable buttons. Help filters entries by each command's permission. Editor text prompts include a cancel button that returns to the relevant menu.

Keep the supplied command placeholders intact when translating button labels or hover text. Configure the existing panel and layout sections rather than inserting manual spaces to align translated text.

## Apply changes

Run `/eggs admin reload`. If validation fails, the current running configuration remains active. Correct the reported value and reload again. Use `/eggs help` and `/eggs admin help` to check both help panels after translating.
