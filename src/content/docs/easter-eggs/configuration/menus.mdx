`plugins/EasterEggs/menus.yml` controls every inventory screen described in [Menus and Editor](/easter-eggs/menus/). Chat text lives in [messages.yml](/easter-eggs/configuration/messages/). Text uses [MiniMessage](https://docs.advntr.dev/minimessage/format.html). Apply changes with `/eggs admin reload`; an invalid layout is rejected and the current menus stay active.

## Layout

```yaml
rows: 6
content-slots: [10, 11, 12, 13, 14, 15, 16, 19, 20, 21, 22, 23, 24, 25, 28, 29, 30, 31, 32, 33, 34]
theme:
  background: 'AIR'
  border: 'BLACK_STAINED_GLASS_PANE'
```

| Key | Description |
| --- | --- |
| `rows` | Inventory height, 3 to 6 rows, shared by all screens |
| `content-slots` | Default item positions for screens without their own entry in `screens` |
| `theme.background` | Item material for empty center slots; `AIR` leaves them empty |
| `theme.border` | Item material for the border; its name and tooltip are hidden |

Slots are **zero-based**: `0` is the top-left slot and, with six rows, `53` is the bottom-right. Write slot lists on one line. Content slots must be unique, inside the inventory, and must not overlap navigation buttons. Lists longer than their slots are paginated.

<Aside type="caution">
Changing `rows` does not move any slots. Update `content-slots`, `screens`, and `buttons` at the same time, or the layout will be rejected.
</Aside>

## sounds

```yaml
sounds:
  enabled: true
  click: 'minecraft:ui.button.click'
  volume: 0.35
  pitch: 1.2
  preference-enabled:
    sound: 'minecraft:block.note_block.pling'
    volume: 0.45
    pitch: 1.6
```

`enabled` switches all menu sounds; players' sound preferences also apply. `click` with `volume` and `pitch` is the ordinary button sound. The named cues below each take `sound`, `volume` (0.0 to 1.0), and `pitch` (0.5 to 2.0). Use `none` for silence.

| Cue | Default sound | Played when |
| --- | --- | --- |
| `preference-enabled` | `minecraft:block.note_block.pling` | A preference is turned on |
| `preference-disabled` | `minecraft:block.note_block.bass` | A preference is turned off |
| `confirm-success` | `minecraft:block.amethyst_block.chime` | An administrator change is saved |
| `confirm-failure` | `minecraft:entity.villager.no` | An action is denied, cancelled, or fails |
| `template-received` | `minecraft:entity.item.pickup` | A placement head is added to your inventory |
| `reset-success` | `minecraft:item.book.page_turn` | Attempts are reset |
| `remove-success` | `minecraft:entity.item.break` | An egg is removed |
| `delete-success` | `minecraft:block.fire.extinguish` | A hunt is deleted |

## titles

Window titles per screen, centered automatically. `<hunt>` is replaced with the hunt's display name where it applies.

```yaml
titles:
  hunts: '<#D8FFF1><bold>Egg Hunts</bold></#D8FFF1>'
  hunt: '<#D8FFF1><bold><hunt></bold></#D8FFF1>'
  admin: '<#FFF0C2><bold>Hunt Editor</bold></#FFF0C2>'
```

## labels

Item names and short display values: buttons (`back`, `start`, `hint`, `leave`, `confirm`), editor tools (`templates`, `placements`, `move`, `copy`, `remove`), settings (`setting-ordered`, `setting-timed-enabled`, `repeat`, `collection`), ranking names (`board-global`, `board-hunt`, `board-cycle`, `board-fastest`), and state words (`state-open`, `repeat-daily`, `collection-shared`, `egg-floating`). Keep named placeholders such as `<page>`, `<pages>`, `<rank>`, and `<player>` intact.

## descriptions

Item lore as lists of lines. Lines longer than the tooltip width wrap automatically and keep their colors. `[]` hides a description. Keep named placeholders such as `<found>`, `<total>`, `<percent>`, `<filled>`, `<remaining>`, `<time>`, `<template>`, and `<order>` intact.

```yaml
descriptions:
  progress:
    - ''
    - '<#DCE3EE><found> <#A8B7C7>/ <total> eggs found'
    - '<#7FFFE1><bold><filled><#526171><remaining></bold> <#DCE3EE><percent>%'
    - ''
    - '<#A8B7C7>Time  <#FFE49A><time>'
```

Missing keys fall back to the bundled defaults, so you only need to keep the entries you change.

Titles, labels, and descriptions follow the `language` selected in `config.yml`. Entries you changed here take priority over the translation; see [Languages](/easter-eggs/configuration/messages/#languages).
