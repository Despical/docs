Storage is configured in `config.yml` under `storage`. There is no separate mysql.yml in 3.0.0.

## SQLite

The default is `storage.type: sqlite`. Data is stored in `plugins/EasterEggs/easter-eggs.db`. No separate storage plugin is needed.

## MySQL

Create a database and a database account with permission to create tables/indexes and read/write rows. Then configure:

```yaml
storage:
  type: 'mysql'
  mysql:
    host: 'localhost'
    port: 3306
    database: 'eastereggs'
    username: 'eastereggs'
    password: 'replace-with-your-database-password'
    ssl: true
```

Restart the server after changing connection settings. Paper downloads and caches the drivers declared by the plugin on first startup.

`ssl: true` uses VERIFY_IDENTITY and requires a trusted TLS certificate matching the hostname. False selects DISABLED. Choose the setting appropriate to your database connection.

## Data movement and multiple servers

Changing the backend selects a different database; it does not move SQLite data or import an older installation. The legacy mysql migration command reads a separate 2.x installation, as described in [operations](/easter-eggs/operations/).

MySQL stores persistent state. It does not provide automatic live cross-server cache invalidation or world-placement synchronization. Plan deployments and verify consistency before sharing a database between running servers.

Back up the database and configuration together. Stop the server before copying SQLite files so its database and any journal files form a consistent backup.
