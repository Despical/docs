## Settings that affect gameplay

- `particles.budget-per-player` limits points emitted per viewer per tick. Zero disables emission; the reduced preference uses one quarter of the budget.
- `particles.tick-interval` controls floating-head transform updates. Each particle preset separately sets its emission interval and view distance.
- `pending.expire-after-seconds` defaults to three hours. Zero removes expiry for newly stored items; existing rows keep their original deadline.
- `leaderboard.boards` enables GLOBAL, HUNT, CYCLE and FASTEST choices. An empty list hides all ranking choices.
- `boss-bar` configures appearance. Enable `boss-bar: true` in a hunt as well; bundled hunts default to false.
- `proximity` sets qualitative hot/warm/cold feedback. The hunt must enable `hints.hot-cold` and the player must allow proximity feedback.
- `egg-sounds` controls placement and interaction sounds. Players may disable their own collection sounds.

The bundled file includes supported ranges and comments for every setting. Reload ordinary settings with `/eggs admin reload`; restart after storage connection changes. Leave `config-version: 3` at its bundled value.
