Each file in `plugins/EasterEggs/particle/` is one effect preset; its file name is the preset ID. Presets are used by [template](/easter-eggs/configuration/templates/#particles) states and by `PARTICLE` [reward actions](/easter-eggs/configuration/rewards/#actions).

Preview any preset privately in front of you with `/eggs admin preview <preset>`. A preview lasts about ten seconds and is visible only to you.

## Complete Example

```yaml
duration-ticks: 0
interval-ticks: 4
view-distance: 24

layers:
  primary:
    shape: 'ORBIT'
    particle: 'DUST'
    points: 12
    radius: 0.44
    height: 0.15
    speed: 0.08
    offset: 0.12
    color: '#FFD54F'
    end-color: '#FFFFFF'
    size: 0.7
  accent:
    shape: 'ORBIT'
    particle: 'DUST'
    points: 3
    radius: 0.33
    height: 0.1
    speed: -0.08
    offset: 0.12
    color: '#FFFFFF'
    end-color: '#FFD54F'
    size: 0.45
```

## Preset Keys

| Key | Default | Range | Description |
| --- | --- | --- | --- |
| `duration-ticks` | `0` | 0 to 1200 | Lifetime of the effect. `0` loops, which suits ambient states. A one-shot effect with `0` ends after 40 ticks; previews last 200 ticks |
| `interval-ticks` | `4` | 1 to 200 | Emit the preset once every N ticks. Higher values send fewer particles without changing the shape |
| `view-distance` | `24` | 1 to 64 | Maximum distance between the viewer and the effect. Ambient searches are also limited by `particles.view-distance` in config.yml |
| `layers` | | 1 to 8 layers | Named layers, emitted in order and combined into one effect |

## Layer Keys

| Key | Default | Range | Description |
| --- | --- | --- | --- |
| `shape` | `RING` | see below | Geometry of the layer |
| `particle` | `DUST` | Bukkit particle name | `DUST` and `DUST_COLOR_TRANSITION` use the color settings. Other particles are accepted only if they need no extra data, for example `END_ROD`, `FLAME`, `SOUL_FIRE_FLAME`, `SNOWFLAKE` |
| `points` | `12` | 1 to 128 | Points sampled per emission |
| `radius` | `0.6` | 0 to 8 | Horizontal size in blocks |
| `height` | `0.8` | 0 to 8 | Vertical size in blocks |
| `speed` | `0.08` | -2 to 2 | Animation phase change per tick; negative reverses, `0` is static |
| `offset` | `0.5` | -4 to 8 | Vertical shift from the head center in blocks |
| `color` | `#FFCA28` | `#RRGGBB` | Dust color, or the start color of a transition. Keep it quoted |
| `end-color` | `#FFFFFF` | `#RRGGBB` | End color, used only by `DUST_COLOR_TRANSITION` |
| `size` | `0.8` | 0.01 to 4 | Dust particle size |

Effects are centered on the egg. Placed heads use the block position plus a quarter block; floating displays follow their configured height and bobbing.

### Shapes

| Shape | Geometry |
| --- | --- |
| `RING` | Horizontal circle that gently rises and falls |
| `HELIX` | Two-turn spiral around the egg |
| `ORBIT` | Circle whose points weave up and down |
| `SPHERE` | Evenly distributed points on a sphere |
| `BURST` | Points expanding outward and falling over the effect's lifetime |
| `FIREFLIES` | Points drifting independently around the egg |
| `HEART` | Heart outline in a vertical plane |
| `STAR` | Five-pointed star outline |
| `COLUMN` | Narrow column of points rising through `height` |
| `WAVE` | Horizontal line rippling up and down |

`BURST` and `COLUMN` use the effect's progress. With `duration-ticks: 0` their progress cycles every four seconds; with a positive duration they play once over that time.

---

## Budgets

Every point counts toward `particles.budget-per-player` in [config.yml](/easter-eggs/configuration/config/#particles), shared across all effects a player sees in the same tick. Eggs closest to the player are drawn first; when the budget is used up, the remaining points are skipped that tick. Only eggs in loaded chunks are processed, and players with particles turned off receive none.
