A template is a reusable appearance. Each file in `plugins/EasterEggs/templates/` defines one, and its file name is the template ID. Templates do not place anything by themselves: administrators choose a hunt and a template when placing each egg. See them in motion in the [video gallery](/easter-eggs/gallery/).

## Complete Example

```yaml
name: '<gold>Golden Egg'
texture: 'c679efc59e22fcf34f7448bf7ab6664f799c3dff656cf483098be36c9ae1'
hint: 'Something golden catches the spring sunshine.'

display:
  mode: 'DISPLAY'
  scale: 1.0
  spin: 1.4
  bob: 0.12
  height: 0.65

particles:
  unfound: 'spring-spiral'
  found: ''
  locked: ''
  collect: 'bunny-hearts'

rewards:
  - 'special-egg'
```

## Keys

| Key | Default | Description |
| --- | --- | --- |
| `name` | file name | MiniMessage name shown in menus and discovery messages |
| `texture` | | Head texture. Either a Mojang texture hash (32 to 64 hex characters) or a Base64 `textures` property whose skin URL is on `textures.minecraft.net`. Keep it quoted |
| `hint` | `Look carefully around the hunt.` | Default clue for eggs of this template. A placement's own clue overrides it |
| `rewards` | `[]` | Extra reward group IDs applied when an egg of this template is discovered, in addition to the hunt's groups |

### display

| Key | Default | Range | Description |
| --- | --- | --- | --- |
| `mode` | `BLOCK` | `BLOCK`, `DISPLAY` | `BLOCK` places a real player-head block. `DISPLAY` shows a floating item display with an invisible interaction hitbox |
| `scale` | `1.0` | 0.1 to 4.0 | Display size multiplier |
| `spin` | `2` | -30 to 30 | Rotation in degrees per tick; negative values reverse, `0` stops |
| `bob` | `0.1` | 0 to 1 | Vertical bobbing amplitude in blocks; `0` disables it |
| `height` | `0.5` | 0 to 3 | Base height above the block, in blocks |

`scale`, `spin`, `bob`, and `height` only affect `DISPLAY`. Update frequency is `particles.tick-interval` in [config.yml](/easter-eggs/configuration/config/#particles). Switching a template between modes keeps every placement's identity, discoveries, and claims; heads are converted the next time they render.

### particles

Each state names a preset from [particle/](/easter-eggs/configuration/particles/), or `''` for no effect. Unknown preset IDs are rejected at load.

| State | Played |
| --- | --- |
| `unfound` | Continuously, to players who have not found the egg while the hunt is available |
| `found` | Continuously, to players who found the egg; not shown if the hunt hides collected eggs |
| `locked` | Continuously, while the hunt is disabled, outside its schedule, or the viewer fails its requirements |
| `collect` | Once, privately to the collector, at the moment of discovery |

Effects respect the per-player particle budget and each player's particle preference.

<Aside>
Create your own template by cloning one, `/eggs admin clone templates golden-egg silver-egg`, then change its `texture` and `name`. Texture hashes come from any head database; follow the original creator's terms when redistributing artwork.
</Aside>
