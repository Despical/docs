## Player menus

Open `/eggs` to browse hunts. Choose a hunt to view its progress and available actions. The collection view distinguishes found and unfound eggs. Timed hunts expose start and leave controls as appropriate.

| Screen | How to reach it |
| --- | --- |
| Hunt list | /eggs |
| Hunt progress and collection | Choose a hunt, or /eggs menu easter |
| Rewards and pool chances | /eggs rewards easter |
| Ranking selection and results | /eggs leaderboard |
| Personal preferences | /eggs preferences |
| Pending item rewards | /eggs inbox, when items are claimable |

Preferences cover particles, sounds, nearby hints and progress bars. Feature-specific hunt settings still apply. Ranking views depend on config.yml; fastest results require timed completions and cycle rankings are unavailable for player-relative cooldown hunts.

## Administrator editor

Open `/eggs admin`, then choose a hunt. Its dashboard links to:

- **Add Eggs:** browse templates and receive placement heads.
- **Placed Eggs:** inspect and manage existing placements.
- **Egg Hints** and **Collection Order:** edit placement clues and ordering.
- **Hunt Rules:** enable the hunt and configure collection behavior.
- **Time Settings:** timer, offline timing and reward periods.
- **Hints & Displays:** text clues, hot/cold feedback, visibility and progress bars.
- **Reset & Removal:** attempt reset and removal tools with confirmation.

Actions respect their individual command permissions. Choosing a template enters placement mode. Leave it with `/eggs admin edit off` before testing collection. Text input prompts include a cancel control.

## Customize inventories

`menus.yml` controls rows, content slots, navigation, titles, item names, lore and menu sounds. Inventory slot indexes are zero-based. Keep content and navigation positions within the configured inventory size and avoid overlapping controls.

Reload with `/eggs admin reload` and open the relevant menu to verify the layout. Chat prompts and help text are configured separately in messages.yml.
