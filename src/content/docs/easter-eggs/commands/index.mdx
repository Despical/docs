`/eggs`, `/eastereggs` and `/ee` share the same command tree. Player and administrator help are separate:

```text
/eggs help
/eggs admin help
```

## Player commands

| Command | Permission | Purpose |
| --- | --- | --- |
| `/eggs` | `eastereggs.menu` | Browse hunts and personal progress. |
| `/eggs menu <hunt>` | `eastereggs.menu` | Open a particular hunt. |
| `/eggs help [page]` | `eastereggs.help` | Read the player guide with hover descriptions and buttons. |
| `/eggs start <hunt>` | `eastereggs.start` | Start or retry an attempt. |
| `/eggs leave <hunt>` | `eastereggs.leave` | Abandon the active attempt. |
| `/eggs hint <hunt>` | `eastereggs.hint` | Request a clue for the next eligible egg. |
| `/eggs rewards <hunt>` | `eastereggs.rewards` | Preview reward rules and pool chances. |
| `/eggs leaderboard [hunt]` | `eastereggs.leaderboard` | Choose an enabled ranking. |
| `/eggs preferences` | `eastereggs.preferences` | Adjust particle, sound, proximity and boss-bar preferences. |
| `/eggs inbox` | `eastereggs.inbox` | Claim pending item rewards or receive an empty-inbox message. |
| `/eggs cancel <token>` | `eastereggs.cancel` | Cancel the active editor prompt using its supplied button. |

Player command permissions default to everyone. Egg collection separately requires `eastereggs.collect`. Hunt entry rules may add permission, prerequisite-hunt or PlaceholderAPI conditions.

The inbox command remains in authorized help and completion when empty. Inventory menu shortcuts to the inbox appear only when there are claimable items.

## Administrator access

Each administrator operation has its own permission and defaults to operators. Grant the specific operations a staff role needs; access to the editor does not grant every command. See the [complete administrator reference](/easter-eggs/commands/admin/).
