Run `/eggs admin help [page]` for the in-game guide. Each operation requires its own `eastereggs.admin.<command>` permission, defaulting to operators.

| Command | Permission suffix | Purpose |
| --- | --- | --- |
| `/eggs admin` | `menu` | Open the hunt editor. |
| `/eggs admin help [page]` | `help` | Read the administrator guide. |
| `/eggs admin give <hunt> <template>` | `give` | Select a hunt/template and receive a placement head. |
| `/eggs admin edit off` | `edit` | Leave placement mode. |
| `/eggs admin place` | `place` | Place the current selection at your position. |
| `/eggs admin remove confirm` | `remove` | Remove the targeted egg. |
| `/eggs admin move` | `move` | Move the targeted egg to your position. |
| `/eggs admin copy` | `copy` | Duplicate the targeted egg with a new UUID. |
| `/eggs admin order <number>` | `order` | Change the targeted egg collection order. |
| `/eggs admin hint <text>` | `hint` | Set the targeted egg hint. |
| `/eggs admin create <id> <name>` | `create` | Create a hunt configuration. |
| `/eggs admin delete <hunt> confirm` | `delete` | Delete an empty, unreferenced hunt. |
| `/eggs admin set <hunts\|templates\|particle> <id> <key> <YAML value>` | `set` | Edit and validate one configuration value. |
| `/eggs admin clone <hunts\|templates\|particle> <source> <destination>` | `clone` | Copy a configuration file to a new ID. |
| `/eggs admin reload` | `reload` | Validate and publish configuration changes. |
| `/eggs admin preview <preset>` | `preview` | Preview a particle preset privately. |
| `/eggs admin migrate <flat\|mysql> <legacy-folder>` | `migrate` | Import legacy data from the console while no players are online. |
| `/eggs admin reset <hunt> <player UUID\|all> confirm` | `reset` | Reset attempts, preserving durable discovery and reward rights. |
| `/eggs admin deliveries` | `deliveries` | List up to fifty uncertain deliveries. |
| `/eggs admin deliveries <id> <retry\|done> confirm` | `deliveries` | Resolve an uncertain delivery after checking its external effect. |

For example, editor access requires `eastereggs.admin.menu` and giving a placement head requires `eastereggs.admin.give`. Use bare `/eggs admin` to open the editor. The edit command accepts only `off`; choosing a hunt/template enters placement mode.

Targeted placement commands require looking at an egg within six blocks. Move and copy use your current position as their destination.

## Validated editing

```text
/eggs admin clone templates painted-egg spring-prize
/eggs admin set templates spring-prize display.mode DISPLAY
/eggs admin set hunts easter boss-bar true
/eggs admin preview pastel-ring
```

Editing and cloning validate the resulting configuration. File edits use `/eggs admin reload`; storage connection changes need a restart.

## Resets and recovery

A reset clears attempt state without renewing already-earned rewards within the same reward period. To create recurring rewards, configure the hunt repeat policy.

`deliveries retry` marks an uncertain action ready to run again; `done` acknowledges it as finished. Check whether its command or economy effect already happened before choosing. See [operations and migration](/easter-eggs/operations/) for the recovery procedure.
