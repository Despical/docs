## Twenty templates in Minecraft

These screenshots and videos were captured in **Minecraft Java Edition 26.3**, running **Easter Eggs 3.0.0** on Paper. Each card shows one configured template with its live ambient particle preset. Play a clip to inspect its motion, or open the still image for a closer look.

The demonstration gallery uses ten floating displays and ten placed heads. Rendering mode is configurable per template; the gallery arrangement is an example setup.
