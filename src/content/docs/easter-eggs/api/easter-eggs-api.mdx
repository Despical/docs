<EasterEggsGuide>

The current public contract is `dev.despical.eastereggs.api.EasterEggsApi`, registered with Bukkit's service manager. See the [complete API guide](/easter-eggs/api/) for compile-only dependencies, method contracts, asynchronous queries and event examples.

The API supplies hunt/template metadata, placements, progress, preferences and leaderboards. Read snapshots on the server thread; callbacks from persisted queries may run on the storage worker.

</EasterEggsGuide>
