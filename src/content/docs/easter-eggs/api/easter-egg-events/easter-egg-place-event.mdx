<EasterEggsGuide>

The 3.0.0 event package is `dev.despical.eastereggs.api.event.egg`. The old EasterEggPlaceEvent class is not the current contract.

| Event | Purpose |
| --- | --- |
| EggPlaceEvent | Cancellable placement proposal |
| EggPlacedEvent | Committed placement notification |
| EggRemoveEvent | Cancellable removal proposal |
| EggRemovedEvent | Committed removal notification |

Access the placement through `event.egg()`. Proposal events can be cancelled before the operation commits; post-events report completed changes. See the [API guide](/easter-eggs/api/) for dependency setup and event registration.

</EasterEggsGuide>
