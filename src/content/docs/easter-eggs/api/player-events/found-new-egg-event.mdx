<EasterEggsGuide>

`FoundNewEggEvent` belongs to the 2.x API. In 3.0.0 use:

- `dev.despical.eastereggs.api.event.egg.EggCollectEvent` to cancel a proposed collection.
- `dev.despical.eastereggs.api.event.egg.EggCollectedEvent` to observe a committed collection and its progress snapshot.
- `dev.despical.eastereggs.api.event.hunt.ProgressChangedEvent` to observe committed progress changes.

Use `event.egg()` for the placement, `event.getPlayer()` for the player and `event.progress()` on the committed collection event for progress. See the [API guide](/easter-eggs/api/) for a listener example and threading requirements.

</EasterEggsGuide>
