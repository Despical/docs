Easter Eggs turns your world into a collection of treasure hunts. Version **3.0.0** provides six bundled hunts, twenty head templates, twenty layered particle presets, player menus and administrator editors.

Use **Paper 1.21.11 or later and Java 25**. Each hunt has its own progress, collection rules, reward period and optional timer. Bundled templates provide appearances; administrators choose every placement.

## See it in game

The [in-game gallery](/easter-eggs/gallery/) includes a screenshot and a six-second particle animation for each of the twenty bundled templates. The [menu guide](/easter-eggs/menus/) shows the player screens and administrator editors.

## Bundled hunts

Global, Easter, Scuba, Halloween, Christmas and Enchanted are installed on first startup. They use personal collection and one-time reward periods by default. Timers, schedules, hot/cold feedback and boss bars can be enabled per hunt.

Heads can be placed as native blocks or floating displays with rotation and bobbing. Players can adjust their particles, sounds, proximity feedback and progress bars. Item rewards that do not fit go to a persistent reward inbox.

## Updating from 2.x

3.0.0 changes the configuration layout, commands, storage and developer API. Follow the [upgrade and operations guide](/easter-eggs/operations/) before replacing a 2.x installation. Legacy imports are explicit, backed up and reported; old configuration behavior is not automatically translated.
