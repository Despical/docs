## Easter Eggs

**Easter Eggs** turns your world into a set of treasure hunts. Hide collectible heads, let players discover them at their own pace or against the clock, and reward milestones, completions, records, and season rankings. Everything is managed from in-game editors, with every setting also available in commented YAML files.

<GameScreenshot src="/images/easter-eggs/gallery-overview.png" alt="Twenty Easter Eggs head templates arranged in a Minecraft demonstration gallery" width={1920} height={1080} />

Watch the [cinematic tour](/easter-eggs/gallery/) to see all twenty bundled templates with their particle effects, or browse each one in its own clip.

Easter Eggs supports **Paper and compatible forks for Minecraft 1.21.11 and later** and requires **Java 25**. Folia is not supported. PlaceholderAPI and Vault are optional integrations; SQLite and MySQL drivers are downloaded by Paper, so no separate database plugin is needed.

---

## Download Easter Eggs

Download the latest plugin JAR from [Hub](https://hub.despical.dev/plugins/easter-eggs), [SpigotMC](https://www.spigotmc.org/resources/eastereggs.116086/), or [BuiltByBit](https://builtbybit.com/resources/easter-eggs.50201/), then follow the [installation guide](/easter-eggs/getting-started/).

Upgrading an older installation? Read [Migrating Legacy Data](/easter-eggs/migration/) before replacing the JAR. The new version refuses to start on an old configuration folder so that nothing is overwritten.

## What's Included

| Bundled content | Details |
| --- | --- |
| **6 hunts** | Global, Easter, Scuba, Halloween, Christmas, and a timed Enchanted challenge |
| **20 head templates** | Five per season: spring, summer ocean, autumn, and winter |
| **20 particle presets** | Layered rings, spirals, orbits, bursts, hearts, stars, and waves |
| **16 reward groups** | Milestones, weighted surprise pools, themed trails, and season rankings |
| **Player menus** | Hunts, collection, rewards, rankings, preferences, and an item inbox |
| **Administrator editor** | Placement, ordering, hints, rules, timing, feedback, and recovery screens |

## Developer API

The public API exposes immutable hunt, template, placement, progress, and leaderboard snapshots through Bukkit's service manager, plus cancellable pre-events and committed post-events for collection, placement, attempts, records, and reward delivery.
