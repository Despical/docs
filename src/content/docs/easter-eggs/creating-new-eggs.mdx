An egg has three parts: a **hunt** containing its rules, a reusable **template** containing its appearance, and a **placement** with its own UUID, world position, order and optional hint. Reusing a template does not merge the discoveries of separate placements.

## Place an existing template

```text
/eggs admin give easter painted-egg
```

Place the supplied head in the world. You can also use `/eggs admin place` to place the current selection at your feet. Use `/eggs admin edit off` before collecting.

The [hunt editor](/easter-eggs/menus/) exposes templates, placed eggs, rules, time settings, hints and collection order.

## Browse the bundled appearances

See the [in-game gallery](/easter-eggs/gallery/) for all twenty templates and their particle animations.

## Create a template

Copy `templates/painted-egg.yml` to a new filename such as `templates/spring-prize.yml`. The filename supplies the template ID. Keep its texture or replace it with a Mojang texture hash or Base64 textures property.

```yaml
name: '<gold>Painted Egg'
texture: '1237cdf6fd4cd4203e68e633d1f38dfe769971127d638843bd516aa97f793f0'
hint: 'A splash of spring color is waiting nearby.'
display:
  mode: 'BLOCK'
  scale: 1.0
  spin: 2.0
  bob: 0.1
  height: 0.5
particles:
  unfound: 'pastel-ring'
  found: ''
  locked: ''
  collect: 'bunny-hearts'
rewards: []
```

Run `/eggs admin reload`, then select your new template:

```text
/eggs admin give easter spring-prize
```

Template files do not place eggs automatically. Configure the effect IDs under `particles` in [particle presets](/easter-eggs/configuration/particles/); reward group IDs refer to [rewards.yml](/easter-eggs/rewards/).

## Floating eggs

Set `display.mode` to `DISPLAY` to use an item display and interaction hitbox. `BLOCK` uses a classic skull block. Scale, spin, bob and height apply to floating displays; spin is degrees per tick and may be negative.

```text
/eggs admin set templates spring-prize display.mode DISPLAY
/eggs admin set templates spring-prize display.spin 2.0
```

## Edit a placement

Look at an egg within six blocks before using a targeted command:

| Command | Result |
| --- | --- |
| `/eggs admin hint A clue beside the old oak` | Set a placement-specific clue |
| `/eggs admin order 1` | Set a nonnegative collection order |
| `/eggs admin move` | Move the targeted egg to your position, retaining its identity |
| `/eggs admin copy` | Create a placement at your position with a new identity |
| `/eggs admin remove confirm` | Remove the targeted placement |

Ordering affects collection when the hunt enables `ordered`. A placement hint overrides the template hint. Copying creates a separate discovery; moving retains the original identity and discovery history.
