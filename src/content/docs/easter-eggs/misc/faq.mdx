## Startup

### "Found data from an older Easter Eggs version"

The `plugins/EasterEggs` folder belongs to an older version. The console prints step-by-step instructions with the exact import command. In short: rename the folder, start the server to create a fresh one, then run the import described in [Migrating Legacy Data](/easter-eggs/migration/).

### "Easter Eggs could not start; existing data was preserved"

Read the error above this line in the console. Common causes are an invalid configuration file, an unreachable MySQL server, wrong credentials, a TLS setting that does not match the database server (`storage.mysql.ssl`), or a placed egg whose hunt or template file was deleted. Nothing is changed while the plugin is disabled; fix the cause and restart.

### "interrupted reward operations require administrator inspection"

The server stopped while rewards were being delivered. Run `/eggs admin deliveries` and resolve each entry. See [Uncertain Deliveries](/easter-eggs/operations/#uncertain-deliveries).

### A deleted hunt or template came back

Bundled files that are missing are restored on every startup. Set `enabled: false` in a bundled hunt instead of deleting it.

## Configuration

### My reload was rejected

The message names the file and the field. The previous configuration is still running, so nothing broke. Common errors are listed in [Operations and Recovery](/easter-eggs/operations/#common-validation-errors).

### `/eggs admin set` stored the wrong type

The value is parsed as YAML. Quote text that contains `#` or `:`, such as colors, times, and dates: `'#FFC107'`, `'18:00'`. Write lists without quotes: `[common, special-egg]`.

### I switched to MySQL and all progress is gone

Changing `storage.type` does not copy data. Switch back to `sqlite` to see the old data again. Choose the backend before players start collecting.

## Placing Eggs

### The placement head does nothing

Placement heads only work in edit mode and with `eastereggs.admin.place`. Edit mode turns on when you take a template from the editor or use `/eggs admin give`; it also ends when you log out. Take a new head from the editor.

### "Choose an Empty Space" or "Spot Already Used"

The block must be air and not already used by another egg. Eggs are stored per block, so two eggs cannot share one.

### "Visit This Area First"

The target chunk is not loaded. Stand near the location and try again.

### "Look at an egg within six blocks"

`move`, `copy`, `order`, `hint`, and `remove` act on the egg you are looking at. Get closer and aim at the head or floating display.

## Collecting Eggs

### Clicking an egg shows "Edit Mode Active"

You are still in edit mode. Run `/eggs admin edit off` or click **[Turn Editing Off]**.

### "Start Your Hunt"

The hunt is timed. Start it from the hunt menu or with `/eggs start <hunt>`.

### "Follow the Trail"

The hunt is ordered. Use `/eggs hint <hunt>` for a clue to the next egg.

### "Hunt Closed" or "Entry Requirements"

The hunt is disabled, outside its schedule, or you do not meet its [requirements](/easter-eggs/hunt-rules/#entry-requirements). `PLACEHOLDER` requirements always fail without PlaceholderAPI.

### "Hunt Already Complete"

You completed this one-time hunt. Repeating hunts use `DAILY`, `WEEKLY`, or `COOLDOWN` [reward periods](/easter-eggs/hunt-rules/#reward-periods).

### Nothing happens when clicking an egg

Check that the player has `eastereggs.collect`, and that another plugin is not cancelling the interaction or `EggCollectEvent`. Rapid repeated clicks within `egg-sounds.interaction-cooldown-millis` are ignored on purpose.

## Visuals

### No particles

Check that `particles.budget-per-player` is above `0`, that the player's **Particles** preference is on, that the template state has a preset, and that the player is within both `particles.view-distance` and the preset's `view-distance`. Hidden collected eggs show no `found` effect.

### Floating eggs are missing after a crash

Display eggs are temporary entities that are recreated whenever their chunk loads. Leftover entities from an interrupted server are cleaned up automatically. Reload or rejoin the area to redraw them.

### No hot and cold messages

All of these are needed: `hints.enabled` and `hints.hot-cold` in the hunt, `preferences.proximity` in config.yml, and the player's **Nearby Hints** preference. Messages only appear within `proximity.radius-blocks` of an unfound egg.

## Rewards

### A reward was not given again after a retry or reset

This is intended. Claims are recorded per reward period, so retries and resets never repeat rewards. Use a [repeating period](/easter-eggs/hunt-rules/#reward-periods) for repeatable rewards.

### Season ranking rewards were not paid

`EVENT_RANK` rewards require `schedule.enabled: true` and a non-empty `schedule.end`. They are settled once after the end, and delivered when each winner is online.

### A command reward did not run

Commands must be written without `/` and must be handled by a plugin. An unhandled command is marked uncertain; see `/eggs admin deliveries`. `MONEY` requires Vault and an economy plugin.

### Items disappeared from the inbox

Inbox items expire after `pending.expire-after-seconds`. Players receive reminders and a warning before expiry.

## Placeholders

### Placeholders show nothing

Make sure PlaceholderAPI was installed before Easter Eggs enabled, then use `%eastereggs_...%` exactly as listed in [PlaceholderAPI](/easter-eggs/placeholders/). Player values exist only for online players. Leaderboard values refresh every ten seconds and only for boards enabled in `leaderboard.boards`.
