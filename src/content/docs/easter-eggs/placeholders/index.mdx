<EasterEggsGuide>

Install PlaceholderAPI to enable Easter Eggs placeholders. The expansion registers automatically; no eCloud download is required.

- [General and per-hunt values](/easter-eggs/placeholders/general/).
- [Leaderboard values](/easter-eggs/placeholders/leaderboard/).

Values come from cached snapshots and may lag recent transactions until refreshed. Player progress values are published for online players; these placeholders do not perform an offline database lookup on demand. Unknown or unavailable values are not synthesized into a ranking entry.

</EasterEggsGuide>
