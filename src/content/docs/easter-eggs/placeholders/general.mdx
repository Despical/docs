<EasterEggsGuide>

PlaceholderAPI must be enabled. Replace `<hunt>` with a configured hunt ID such as `easter`.

| Placeholder | Value |
| --- | --- |
| %eastereggs_total% | Total placed eggs across hunts |
| %eastereggs_total_type% | Configured template count |
| %eastereggs_total_found% | Player discoveries across current hunt progress |
| %eastereggs_total_left% | Eggs remaining across current hunt progress |
| %eastereggs_hunt:&lt;hunt&gt;:total% | Eggs placed in the hunt |
| %eastereggs_hunt:&lt;hunt&gt;:found% | Player discoveries in that hunt |
| %eastereggs_hunt:&lt;hunt&gt;:left% | Remaining eggs in that hunt |
| %eastereggs_hunt:&lt;hunt&gt;:percent% | Integer percentage, from 0 through 100 |
| %eastereggs_hunt:&lt;hunt&gt;:status% | Attempt status, or NOT_STARTED |
| %eastereggs_hunt:&lt;hunt&gt;:cycle% | Current progress reward-period identifier |
| %eastereggs_hunt:&lt;hunt&gt;:time% | Formatted attempt duration, or 0s |

For example, `%eastereggs_hunt:easter:found%` gives a player's current Easter discoveries. Progress comes from committed cached snapshots for online players. A new player may show zero or NOT_STARTED until an attempt exists or loading finishes.

</EasterEggsGuide>
