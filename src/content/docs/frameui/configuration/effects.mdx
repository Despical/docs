title: Effect Files
description: FrameUI effect YAML reference for IDs, templates, timing, captions, images, palettes, screen elements and presentation.
---

Each definition is stored in `plugins/FrameUI/effects/<id>.yml`. Copy a bundled definition or export one from Studio to keep all settings consistent.

## Identity and Selection

| Key | Meaning |
| --- | --- |
| `id` | Match the filename without `.yml`. Use lowercase letters, digits and single hyphens, up to 48 characters. |
| `name` | Display name, up to 64 characters. |
| `template` | One of the 50 stable animation IDs in the [gallery](/frameui/effects/). Presets are compositions built on these templates. |
| `category` | Library group. Bundled IDs resolve to Animations or Presets; custom IDs appear under My Effects. Up to 40 characters. |
| `enabled` | Whether the effect is eligible; defaults to `true`. |
| `priority` | Integer from `-10000` to `10000`; highest eligible value wins. Default `0`. |
| `weight` | Integer from `1` to `10000`; random-selection weight among equal priorities. Default `1`. |
| `play-on` | List of automatic base or native addon events. Empty means manual-only; `command` is not an automatic binding. |

Connected Studio creates a copy of a bundled definition rather than overwriting it. New custom definitions appear under **My Effects**. Keep the template ID when giving a copy its own ID.

## Example Custom Effect

```yaml
id: 'lobby-aurora'
name: 'Lobby Aurora'
template: 'aurora'
enabled: true
priority: 0
weight: 1
play-on: ['join']

timing:
  fade-in-ticks: 14
  minimum-ticks: 64
  maximum-ticks: 84
  fade-out-ticks: 16

captions:
  enabled: true
  title: 'Welcome, {player}'
  subtitle: 'Your next adventure starts here'
  join-detail: 'Joining {world}'
  teleport-detail: 'Travelling to {world}'
  preview-detail: '{effect} preview'

appearance:
  palette: 'custom'
  background: '#081221'
  primary: '#7FAEFF'
  secondary: '#C2D6FF'
  speed: 1.0
  intensity: 1.0
  image: ''

filters:
  worlds:
    include: ['lobby']
```

Save as `lobby-aurora.yml`, reload and test in `lobby` with `/frameui preview lobby-aurora`. Omitted optional keys use schema defaults. Unknown settings reject the definition.

## Timing

All YAML timing values use server ticks: **20 ticks = 1 second**.

| Key | Meaning |
| --- | --- |
| `fade-in-ticks` | Entrance length; may be zero. |
| `minimum-ticks` | Earliest release point measured from the start, including the entrance. |
| `maximum-ticks` | Latest release point while waiting for world readiness. |
| `fade-out-ticks` | Exit length after release; at least one tick. |

For the example, entrance is `0.7s`, hold is `2.5s`, exit is `0.8s` and extra loading wait is up to `1s`. The normal duration is `(minimum-ticks + fade-out-ticks) / 20`, or `4s`.

Each timing value is bounded to `1200` ticks. `minimum-ticks` must be at least `fade-in-ticks`; `maximum-ticks` must be at least `minimum-ticks`; maximum plus exit must not exceed `2400` ticks. Studio displays these phases in seconds under **Motion**.

## Captions

Caption text is plain text. Built-in replacements are `{player}`, `{world}`, `{source-world}` and `{effect}`. Optional PlaceholderAPI support expands installed placeholders in captions. Caption colors are `title-color`, `subtitle-color` and `detail-color` under `captions`.

`captions.enabled` controls the three built-in caption lines. `title` allows up to 64 characters, `subtitle` up to 96, and each detail string up to 128. Each line has its own background and text styles, such as `title-background`, `title-background-opacity` and `title-font-size`; see [Text Style Reference](#text-style-reference). Use quoted six-digit hex colors, including the leading `#`.

`join-detail`, `teleport-detail` and `preview-detail` select the detail text for the corresponding context. The browser preview uses sample values; test dynamic text in Minecraft.

## Appearance and Images

| Setting | Accepted values |
| --- | --- |
| `palette` | `original` or `custom` |
| `background`, `primary`, `secondary` | Six-digit hex colors such as `#7FAEFF` |
| `speed` | `0.05`–`8.0`; ambient motion speed, independent of duration |
| `intensity` | `0.0`–`4.0` |
| `image` | Empty, or a local PNG path under `images/` |
| `image-fit` | `cover` fills the area; `contain` keeps the whole image visible |
| `image-opacity` | `0.0`–`1.0` |
| `image-motion` | `still`, `panorama`, `page` |
| `title-motion` | `still`, `grow`; use Studio's individual caption controls for new designs |

Plugin PNGs must be no larger than **8 MiB** and **2048 × 2048** pixels. Use local files, not remote URLs. Studio accepts PNG/JPEG input and includes a PNG in the export.

## Screen Elements

The `elements` section controls composition:

- `background`: `template`, `solid`, `split`, `grid`, `terminal`, `pulse`, `none`.
- `image-animation`: `inherit`, `fade`, `grow`, `slide-up`, `slide-left`, `slide-right`, `slide-down`, `wipe`, `page`, `none`.
- `progress`: `none`, `bar`, `segments`, `dots`, `ring`.
- `decoration`: `none`, `embers`, `petals`, `scan`, `pulse`.
- `text-animation` and individual `title-animation`, `subtitle-animation`, `detail-animation`: `still`, `grow`, `slide-up`, `slide-down`, `slide-left`, `slide-right`, `none`.

Image, text and indicator position, scale and stretch controls live in the same section. Positions use normalized screen coordinates, where `0.5` is the center. Individual caption offsets, scale and stretch can refine the shared text layout. Use [direct editing in Studio](/frameui-studio/design/) to place elements visually.

### Placement and Size

All keys below belong under `elements`. X grows to the right and Y grows downward from the top-left corner. Positions outside `0`–`1` let an element extend beyond the screen.

| Key | Default | Accepted values |
| --- | --- | --- |
| `image-x`, `image-y` | `0.5`, `0.5` | `-10` to `10` |
| `image-scale` | `1` | `0.01` to `10` |
| `image-stretch-x`, `image-stretch-y` | `1` | `0.01` to `10` |
| `image-delay` | `0` | `0` to `0.8`; entrance delay as a fraction of the entrance phase |
| `text-x`, `text-y` | `0.5`, `0.64` | `-10` to `10`; shared caption placement |
| `text-scale`, `text-stretch-x`, `text-stretch-y` | `1` | `0.01` to `10` |
| `progress-x`, `progress-y` | `0.5`, `0.8` | `-10` to `10` |
| `progress-width` | `0.34` | `0.01` to `2` |
| `progress-scale` | `1` | `0.05` to `20` |
| `title-offset-x`, `subtitle-offset-x`, `detail-offset-x` | `0` | `-20` to `20`; individual caption offsets |
| `title-offset-y`, `subtitle-offset-y`, `detail-offset-y` | `0` | `-20` to `20` |
| `title-scale`, `subtitle-scale`, `detail-scale` | `1` | `0.01` to `10` |
| `title-stretch-x`, `subtitle-stretch-x`, `detail-stretch-x` | `1` | `0.01` to `10` |
| `title-stretch-y`, `subtitle-stretch-y`, `detail-stretch-y` | `1` | `0.01` to `10` |

Individual caption transforms apply after the shared text transform. Omitted caption animation keys inherit `text-animation`; legacy `appearance.title-motion: grow` can supply the title entrance when the shared animation is omitted.

Loading indicators are animated decoration; they do not measure the server's actual loading progress.

### Indicator and Image Backgrounds

These keys belong under `elements`:

| Key | Default | Accepted values and behavior |
| --- | --- | --- |
| `progress-priority` | `15` | Integer from `-100` to `100`; higher draws in front. |
| `progress-opacity` | `1` | `0` to `1`; affects the indicator and its background, without hiding ambient decoration. |
| `progress-background` | `#081221` | Six-digit hex color behind the indicator. |
| `progress-background-opacity` | `0` | `0` to `1`; `0` hides the background. |
| `progress-padding` | `6` | `0` to `32` reference pixels at 640 × 360; decimals are supported. |
| `image-background` | `#081221` | Six-digit hex color behind transparent pixels of the main image. |
| `image-background-opacity` | `0` | `0` to `1`; shares the main image's placement, entrance and overall opacity. |

```yaml
elements:
  progress: 'dots'
  progress-priority: 25
  progress-opacity: 1
  progress-background: '#211622'
  progress-background-opacity: 0.72
  progress-padding: 7
  image-background: '#081221'
  image-background-opacity: 0
```

Additional image objects use their existing unprefixed `background` and `background-opacity` keys inside `elements.objects.<id>`, together with `opacity` and `priority`. An opaque image covers its background. Indicator backgrounds are not drawn when `progress` is `none`. All new backgrounds default to transparent, preserving saved designs that omit these keys.

## Additional Text and Images

`elements.objects` adds independently positioned objects alongside the main image and three built-in captions. An effect supports **up to 12 extra text objects and 8 extra images**, with at most 20 objects in total. Object IDs begin with a lowercase letter and contain up to 32 lowercase letters, digits or hyphens.

```yaml
elements:
  objects:
    server-label:
      type: 'text'
      text: 'Welcome to {world}'
      color: '#F1F4FA'
      x: 0.5
      y: 0.25
      scale: 1
      animation: 'fade'
      font-size: 120
      align-x: 'center'
      background: '#081221'
      background-opacity: 0.6
      padding: 4
      priority: 30
    server-logo:
      type: 'image'
      image: 'images/logo.png'
      x: 0.5
      y: 0.4
      scale: 0.5
      fit: 'contain'
      opacity: 1
      animation: 'grow'
      priority: 10
```

Place `logo.png` in `plugins/FrameUI/images/` before loading this example. Additional image paths must be flat `images/<name>.png` paths; the filename may contain letters, digits, underscores and hyphens. The main `appearance.image` also permits subdirectories inside `images/`.

| Object key | Default | Accepted values |
| --- | --- | --- |
| `type` | `text` | `text` or `image` |
| `text` | `Text` | Plain text, up to 128 characters; supports the same dynamic replacements as captions |
| `color` | `#F1F4FA` | Six-digit hex text color |
| `image` | Empty | Required local PNG path for an image object |
| `x`, `y` | `0.5` | `-10` to `10` |
| `scale`, `stretch-x`, `stretch-y` | `1` | `0.01` to `10` |
| `opacity` | `1` | `0` to `1` |
| `fit` | `contain` | `cover` or `contain` |
| `animation` | `fade` | `fade`, `grow`, `slide-up`, `slide-down`, `slide-left`, `slide-right`, `none`; images also allow `wipe` and `page` |
| `background` | `#081221` | Six-digit hex color |
| `background-opacity` | `0` | `0` to `1` |
| `priority` | `20` for text, `10` for images | Integer from `-100` to `100` |

Extra text also accepts every unprefixed key in [Text Style Reference](#text-style-reference). Studio preserves these objects in connected saves and YAML/ZIP exports. Across the loaded library, effects and additional image layers share a limit of 256 shader slots.

## Player Presentation

```yaml
presentation:
  show-hands: false
  hide-hud: true
  block-movement: true
  block-interactions: true
```

Showing hands requires `hide-hud: false`. These settings apply while the screen is active. Always verify the final player view in Minecraft, including screen cleanup.

See [Filters and Selection](/frameui/filters/) for the `filters` section and [Automatic Playback](/frameui/automatic-playback/) for `play-on`.

## Text Style Reference

Built-in caption styles use keys such as `captions.title-font-size`, `captions.subtitle-align-x` and `captions.detail-shadow-offset`. The prefixes are `title-`, `subtitle-` and `detail-`. Additional text uses the same unprefixed keys inside `elements.objects.<id>`.

| Style key | Accepted values |
| --- | --- |
| `font-size` | `10` to `400` percent |
| `box-width` | `0` to `1024` font units; `0` is automatic |
| `box-height` | `0` to `256` font units; `0` is automatic |
| `align-x` | `left`, `center`, `right` |
| `align-y` | `top`, `middle`, `bottom` |
| `padding` | `0` to `32` font units |
| `opacity` | `0` to `1` for lettering |
| `rotation` | `-180` to `180` degrees |
| `background` | Six-digit hex color |
| `background-opacity` | `0` to `1` |
| `shadow` | Boolean |
| `shadow-color` | Six-digit hex color |
| `shadow-offset` | `0` to `8` font units, including decimals |
| `outline-width` | Integer `0` to `3` font units |
| `outline-color` | Six-digit hex color |

Automatic boxes follow text size and reserve alignment room. Alignment changes move only the lettering. Explicit dimensions stay fixed when font size changes.

## Composition Priority

`elements.image-priority`, `elements.progress-priority`, `elements.title-priority`, `elements.subtitle-priority`, `elements.detail-priority` and an object's `priority` accept integers from `-100` to `100`. Higher values draw in front; equal priorities retain the established order. The indicator defaults to `15`, the base image and extra images default to `10`, and captions/text default to `20`. An element's background shares its priority and stays behind its own content.

These values are independent of top-level effect `priority`, which selects effects rather than controlling drawing order. Studio preserves composition priorities and text styles in YAML, ZIPs and connected saves.
