Welcome to **Warden Party**. This plugin lets you run configurable Warden boss encounters with custom health logic, scheduled spawns, reward commands, Phantom support, and [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) integration.

---

## Prerequisites

Before installing **Warden Party**, make sure your server meets these requirements:

* **Java Version:** [Java 21](https://www.oracle.com/java/technologies/downloads/) for Minecraft 1.21.11. **Java 25** is required for Minecraft 26.x.
* **Server Software:** [**Paper**](https://papermc.io/) or a Paper-compatible fork is required.
* **Minecraft Version:** **1.21.11 - 26.3**. Paper **26.3** is recommended and was checked with Warden Party 1.8.9.
* [**PlaceholderAPI**](https://www.spigotmc.org/resources/placeholderapi.6245/) <Badge text="Optional" variant="tip" /> : Required only if you plan to use the built-in placeholders.
* **Permissions Plugin** <Badge text="Optional" variant="tip" /> : A plugin such as [LuckPerms](https://www.spigotmc.org/resources/luckperms.28140/) helps manage admin access cleanly.
* **[MythicMobs](/warden-party/integrations/mythicmobs/)** <Badge text="Optional" variant="tip" /> : MythicMobs 5.x for spawning a custom mob base. Use a release compatible with your server version.
* **[ModelEngine](/warden-party/integrations/modelengine/)** <Badge text="Optional" variant="tip" /> : ModelEngine 4.x for custom models, with its generated resource pack installed on clients.

## Installation

Setting up **Warden Party** is straightforward. Follow these steps to get started:

<Steps>
    1. Download the latest **Warden Party** build from [Hub](https://hub.despical.dev/plugins/warden-party), [SpigotMC](https://www.spigotmc.org/resources/warden-party.117447/) or [BuiltByBit](https://builtbybit.com/resources/warden-party.50166/).
    2. Place the `warden-party-x.x.x.jar` file into your server's `plugins/` directory.
    3. Restart the server to generate the default configuration files.
    4. Join the server and run `/wp` to verify that the plugin loaded correctly.
</Steps>

---

## First-Run Configuration

On first startup, the plugin generates a dedicated folder containing two main files:

* `config.yml`: Boss definitions, schedulers, natural spawn rules, reward commands, and combat settings.
* `messages.yml`: Command feedback, permission warnings, cooldown messages, and placeholder fallback text.

When upgrading from 1.8.8, replace the plugin JAR while the server is stopped and keep your configuration files. Bosses without an `appearance` section retain the normal Warden behavior. To use the new integrations, merge an example from the [MythicMobs](/warden-party/integrations/mythicmobs/) or [ModelEngine](/warden-party/integrations/modelengine/) guide into an existing profile; do not replace the entire profile with a partial snippet.

---

## First Test Flow

For a clean first test, use this order:

* Leave the default Warden definition in place.
* Join a non-peaceful world.
* Run `/wp summon` to spawn the default Warden at your location.
* Hit the boss a few times to confirm cooldowns, sounds, and health tracking behave as expected.
* If Phantom mode is enabled, continue until the configured threshold is reached and verify the fight phase changes correctly.

<Aside type="caution">
    **Warden Party** will not spawn a boss in worlds running on `peaceful` difficulty.
</Aside>
