## FrameUI Studio

**FrameUI Studio** is the browser editor for [FrameUI](/frameui/). Choose from 50 animations and 10 ready-made presets, then customize text, colors, images, motion, event bindings and the player's view. Drag and resize elements directly on the preview.

<a href="https://frameui.despical.dev/" target="_blank" rel="noopener noreferrer">Open FrameUI Studio</a>. No account is required. You can edit and export without connecting to a server, or open `/frameui editor` in Minecraft to import and save directly.

To use your effects in Minecraft, <a href="https://hub.despical.dev/plugins/frameui" target="_blank" rel="noopener noreferrer">get the FrameUI plugin on Plugin Hub</a>.

Studio offers 28 interface languages through its header selector. Your effect content stays as you wrote it. The editor adapts to desktop, tablet and mobile; verify the finished design in Minecraft before using it for players.

## Text and Layout Tools

Style individual text elements with font size, alignment, backgrounds, shadows, outlines and rotation. Automatic text boxes stay fixed when alignment changes; explicit dimensions define a custom box. Layer priority controls which element appears in front.

Use the alignment icon beside **Loop** for canvas and element guides. The header's **Transfer** menu groups local import and ZIP export. See [Design and Layout](/frameui-studio/design/) for typography/snapping and [Library and Shortcuts](/frameui-studio/library/) for keyboard controls.
