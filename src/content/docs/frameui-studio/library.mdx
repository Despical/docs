## Your Library

**Animations** contains 50 reusable motion templates. **Presets** contains 10 composed starting points. **My Effects** contains custom drafts and, while connected, custom server designs. Search narrows the visible category.

Changing a bundled design creates a custom copy with its own identity. The bundled original stays available as a starting point. A display name is readable text; an effect ID is the filename and command identifier.

## Drafts and Server Changes

Studio keeps drafts and image data in browser storage. Local edits do not become server changes until **Import to server** or **Save to server** succeeds. A connected server effect can have unsaved local changes, so check the action/status before leaving.

Storage belongs to the current browser and site origin. A different browser, device, private session or site address may have a different library. Clearing site data can remove drafts. Export ZIP backups for work you need to retain.

## Undo, Redo and Reset

Use the header undo/redo buttons or keyboard shortcuts. A completed direct manipulation is one history change. **Reset** on the main effect restores its template defaults; inside a selected component it restores that component. Undo can recover the previous draft after a reset.

Permanent deletion is separate from undo. Review the delete confirmation and export a backup before confirming, especially for connected server effects.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+Z` | Undo outside text fields. |
| `Ctrl/Cmd+Shift+Z` | Redo outside text fields. |
| `/` | Focus effect search outside text fields. |
| Space with page body focused | Play or pause the preview. |
| `Escape` | Cancel a manipulation or clear canvas selection. |
| Arrow keys | Nudge a focused canvas element or handle. |
| `Shift` + arrow keys | Use a larger nudge step. |
| Left/right arrows on a tab | Move between inspector tabs. |
| Home/End on a tab | Select the first/last inspector tab. |

## Language and Storage Preferences

The header language selector changes Studio's interface and remembers an explicit selection. It does not translate your effect names or captions or change exported IDs.

Use **Cookie settings** in the footer to revisit site preferences. Essential storage supports drafts and preferences. Export your designs before clearing browser site data.
