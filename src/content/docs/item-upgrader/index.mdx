## Item Upgrader

**Item Upgrader** lets players transform a held item into a configured result through a protected graphical menu. Every upgrade can define its source identity, output item, quantity, success chance, Vault price, required ingredients, enchantment behavior, item flags, model data, and failure result.

The plugin supports vanilla materials and custom items from Oraxen, ItemsAdder, and EcoItems. Multiple recipes can form upgrade chains, while permissions and allowed-world settings control where the menu is available.
