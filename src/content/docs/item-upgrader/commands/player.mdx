title: Player Commands

---

Player Commands are available to **regular players** and do not require administrative permissions. These commands allow players to open the **Item Upgrader** menu for the item in their main hand.

All commands use `/itemupgrader`. The internal command fallback prefix is `iupgrader`.

---

## Main Command

Opens the **Item Upgrader** menu for the item in the player's main hand.

No built-in permission is required by default. You can set `upgrade-menu-perm` in `config.yml` to require a custom permission node.

```bash
/itemupgrader
```

Before opening the menu, the plugin verifies that addon items have finished loading, the current world is allowed, the held item is upgradeable, no disallowed enchantment is present, and all required items are available.
