## Port Bridge

**Port Bridge** connects your local Minecraft Java server to friends through a public TCP relay. Keep the world on your own computer, open a managed Bore tunnel, and share the connection address from chat or the console. The plugin checks the Minecraft route, shows connection details, and reconnects after interruptions.

<GameScreenshot src="/images/portbridge/cover.png" alt="Port Bridge cover with a cyan network bridge connecting a local Minecraft server to a village" width={1774} height={887} />

Follow the [installation guide](/port-bridge/getting-started/) to share your first address, or read [tunnels and relays](/port-bridge/tunnels-and-relays/) to understand how the connection works. Select the cover to enlarge it without leaving the documentation.

Port Bridge supports **Paper and compatible forks for Minecraft 1.21.11 and later** and requires **Java 25 or newer**. Folia and Spigot are not supported. Managed Bore downloads are available for Windows x64/x86 and Linux/macOS x64/ARM64.

---

## Download Port Bridge

Download the latest plugin JAR from [Hub](https://hub.despical.dev/plugins/port-bridge) or [GitHub Releases](https://github.com/Despical/PortBridge/releases), then follow the [installation guide](/port-bridge/getting-started/). Install `port-bridge-<version>.jar`; you do not need to compile the plugin yourself.

The plugin is free and open source under [GPL-3.0-or-later](https://github.com/Despical/PortBridge/blob/main/LICENSE). The plain and Javadoc JARs are developer artifacts.
