---
title: Permissions
description: Port Bridge permission nodes for connection addresses, status, tunnel management and reloads.
---

All permissions default to operators. `portbridge.admin` grants the four command permissions below.

| Permission | Purpose |
| --- | --- |
| `portbridge.status` | View status and command help. |
| `portbridge.address` | View/copy the address and receive connection announcements. |
| `portbridge.manage` | Start, stop and restart the tunnel. |
| `portbridge.reload` | Validate and reload configuration and messages. |
| `portbridge.admin` | Grant all of the above. |

The optional join notification also checks `portbridge.address`. Its delayed callback rechecks the player, current preference, permission and tunnel state before sending a panel.

Chat controls hide actions the sender cannot use. Displaying a copy control does not grant management permissions. Framework denial text can be customized through `acf.acf-core.permission_denied` in [messages.yml](/port-bridge/configuration/messages/).
