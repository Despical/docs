`messages.yml` contains user-facing chat and menu text. Values support Adventure MiniMessage formatting, including gradients, hex colors, and text decorations.

---

## Message Formatting

```yaml
prefix: '<#8BD5CA>Particle Text</#8BD5CA><#606A7B>:</#606A7B> '
renderer-created: '%prefix%<#91B78A>Created <#DCE3EE>%id% <#91B78A>with the cached defaults.'
```

Keep placeholders such as `%prefix%`, `%id%`, `%label%`, `%version%`, `%particle%`, and `%amount%` intact when they are used by a message.

Plain variables also accept `<name>` syntax. Renderer text is inserted as literal text, so user content does not become MiniMessage markup. PlaceholderAPI values are resolved for player recipients when the integration is installed.

## Chat Panels

The `chat` section controls the help, renderer list, and info card layouts, including hover descriptions, action labels, and page navigation. The `usage` and `description` sections supply each command's syntax and help text. Help rows are built from commands the sender has permission to use.

```yaml
chat:
  help-title: '<#DCE3EE><bold>Particle Text Commands</bold></#DCE3EE>'
  help-row: '  <#606A7B>•</#606A7B> %command% <#606A7B>·</#606A7B> <#B8C2D4>%description%</#B8C2D4>'
  navigation: '  %previous% <#8792A6>%page% / %pages%</#8792A6> %next%'
usage:
  help: '/%label% help [page]'
  list: '/%label% list [page]'
  info: '/%label% info <id>'
description:
  help: 'Browse commands you can use.'
  list: 'Browse saved renderers.'
  info: 'Inspect and manage a renderer.'
```

`%command%`, `%name%`, `%actions%`, `%previous%`, and `%next%` can carry clickable components. Keep these variables in the corresponding row and navigation templates to retain interaction.

## Unchanged Values and Failures

Already-enabled or already-disabled renderers use `renderer-already-enabled` and `renderer-already-disabled`. Repeated text, scale, font, particle, inverted-mode, rotation, and location requests use their respective `renderer-*-unchanged` messages.

```yaml
renderer-already-disabled: '%prefix%<#FF5555>Renderer <#DCE3EE>%id% <#FF5555>is already disabled.'
renderer-text-unchanged: '%prefix%<#FF5555>Renderer <#DCE3EE>%id% <#FF5555>already contains that text.'
invalid-page: '%prefix%<#FF5555>Choose a page between 1 and %pages%.'
reload-failed: '%prefix%<#FF5555>Reload rejected: %reason%. The active configuration was kept.'
```

---

## Menu Text

Renderer names, lore, pagination buttons, and empty-menu text are also stored in `messages.yml`. The inventory title itself is configured under `menu.title` in `config.yml`.

<Aside type="caution" title="Apply changes safely">
Run `/pt reload` after editing this file. Invalid MiniMessage syntax may cause formatting to appear differently than intended.
</Aside>
