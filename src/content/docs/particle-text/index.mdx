## Particle Text

**Particle Text** renders persistent text displays from native Minecraft particles. Server owners can create, position, style, rotate, enable, and manage renderers without restarting the server.

Built for modern Paper servers, **Particle Text** includes command and inventory-based management, configurable fonts and particles, three-axis rotation, dynamic PlaceholderAPI text, persistent YAML storage, cached point clouds, distance filtering, pixel sampling, and per-renderer particle limits.
