---
title: Admin Commands
description: Commands for creating, editing, positioning, inspecting, and reloading Particle Text renderers.
---

All Particle Text management commands use `/pt`. The full `/particletext` alias is also available. Commands use Aikar's annotation system with native Paper suggestions. Operators receive the administrative permissions by default through `particletext.admin`.

---

## Create Command

Creates a renderer at the executing player's location using the configured defaults.

```bash
/pt create <id> <text>
```

**Permission:** `particletext.command.create`
**Sender:** Player only

---

## Delete Command

Permanently removes a renderer and its saved data.

```bash
/pt delete <id>
```

**Permission:** `particletext.command.delete`

---

## List Command

Browses saved renderer IDs and their enabled state. Players with the info permission can hover for details and click an ID to open its management card.

```bash
/pt list [page]
```

**Permission:** `particletext.command.list`

Pages start at `1` and use `chat.page-size` from `config.yml`.

---

## Info Command

Shows a renderer's text, status, particle count, font, transform, and location. Players see permitted teleport, edit, enable/disable, and delete actions. Edit and delete buttons fill in a command for review.

```bash
/pt info <id>
```

**Permission:** `particletext.command.info`

---

## Menu Command

Opens the interactive renderer management inventory.

```bash
/pt menu
```

**Permission:** `particletext.command.menu`
**Sender:** Player only

---

## Teleport Commands

Teleports you to a renderer or moves a renderer to your current location.

```bash
/pt teleport <id>
/pt tphere <id>
```

**Permission:** `particletext.command.teleport`
**Sender:** Player only

---

## Move Command

Moves a renderer relative to the direction the player is facing. If omitted, the amount comes from `commands.default-move-amount`, which defaults to `0.25` blocks.

```bash
/pt move <id> <forward|backward|left|right|up|down> [amount]
```

**Permission:** `particletext.command.edit`
**Sender:** Player only
**Amount range:** `0.01` to `100.0`

---

## Text Command

Changes the displayed text. The configured `performance.max-text-length` limit applies.

```bash
/pt text <id> <text>
```

**Permission:** `particletext.command.edit`

---

## Size Command

Changes the world-space scale of the renderer.

```bash
/pt setsize <id> <scale>
```

**Permission:** `particletext.command.edit`
**Scale range:** `0.01` to `10`

---

## Font Command

Changes the Java AWT font family, style, and rasterization size.

```bash
/pt font <id> <name> <style> <size>
```

**Permission:** `particletext.command.edit`
**Styles:** `PLAIN`, `BOLD`, `ITALIC`, `BOLD_ITALIC`
**Size range:** `4` to `128`

Run `/pt fonts` to list font families available in the server's Java environment. It uses the same edit permission.

---

## Particle Command

Changes the renderer to a supported data-free Bukkit particle.

```bash
/pt particle <id> <particle>
```

**Permission:** `particletext.command.edit`

---

## State Commands

Enables or disables a renderer, or switches between glyph and background pixels.

```bash
/pt enabled <id> <true|false>
/pt inverted <id> <true|false>
```

**Permission:** `particletext.command.edit`

---

## Rotate Command

Sets the rotation angle for one axis. Angles are expressed in degrees.

```bash
/pt rotate <id> <x|y|z> <angle>
```

**Permission:** `particletext.command.edit`

Requests that leave text, scale, font, particle, enabled state, inverted state, or rotation unchanged return an error message instead of reporting a successful edit. Moving or teleporting to the exact current location also reports that nothing changed.

---

## Reload Command

Reloads cached settings, messages, renderer data, and the render task.

```bash
/pt reload
```

**Permission:** `particletext.command.reload`

---

## Help and Version Commands

```bash
/pt help [page]
/pt version
```

**Help permission:** `particletext.command.help`
**Version permission:** `particletext.command.version`

The version permission is granted to all players by default. Standard tab completions require `particletext.command.tabcomplete`.

Help is paginated with `chat.page-size` and shows only commands the sender can use. Players can hover for descriptions and click to fill in a command.
