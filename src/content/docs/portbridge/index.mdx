**PortBridge** connects your running local Minecraft Java server to friends through a public TCP relay. It manages the Bore client, shows a copyable address and checks that Minecraft responds through the route.

<GameScreenshot src="/images/portbridge/cover.png" alt="PortBridge cover: a cyan network bridge connects a local server island to a Minecraft village" width={1774} height={887} />

The plugin targets **Paper and compatible forks for Minecraft 1.21.11+**. Use **Java 25 or newer** for every supported server version. Folia and Spigot are not supported. Read the [compatibility reference](/portbridge/compatibility/) for validation details.

## Download

Download `portbridge-<version>.jar` from [GitHub Releases](https://github.com/Despical/PortBridge/releases), then follow [Getting Started](/portbridge/getting-started/). The plugin is free and open source under [GPL-3.0-or-later](https://github.com/Despical/PortBridge/blob/main/LICENSE).
