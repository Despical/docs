## Eat Everything 🍖

**Eat Everything** lets players eat literally anything in Minecraft. Pick a sword, a stick, a diamond or a whole block, decide how much hunger it restores, how long it takes to eat, which potion effects it applies, what it leaves behind and which commands run when the last bite is gone.

It is a [Paper](https://papermc.io/) plugin built on Minecraft's modern **item data components**, the same `food` and `consumable` components the game itself uses. Nothing is faked with scheduled tasks or custom NBT tricks, so your edible items behave exactly like vanilla food: the eating animation, the particles, the sound, the hunger bar and the hotbar cooldown overlay all work as players expect.
