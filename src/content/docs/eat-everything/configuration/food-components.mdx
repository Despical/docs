`food-components.yml` is where you define foods once and let the plugin apply them to every matching item on the server. Each entry under `food:` is one **component**.

<Aside type="tip">
    Prefer a visual workflow? Prototype with [`/ee` commands](/eat-everything/features/live-item-editing), run `/ee info`, then copy the numbers into this file.
</Aside>

---

## File Layout

```yaml
food:
  my-food:              # the component ID
    item: STICK         # required: the material
    components:         # everything below is optional
      nutrition: 3
      saturation: 1
      # ...
```

* **The ID** (`my-food`) is what you type in `/ee item my-food`. IDs are case-insensitive, so `My-Food` and `my-food` are the same food for `/ee item`. Do not define two IDs that differ only in case; the later one wins for that command.
* **`default`** is a documentation example. It is **never** loaded, whatever it contains.
* **Order matters.** If several entries use the same material, the first one whose [conditions](#conditions) match wins.
* Every option has a default. A missing or invalid value falls back to it, and mistakes are written to the console. See [Troubleshooting](/eat-everything/misc/troubleshooting).

---

## `item`

The material that becomes edible, for example `STICK`, `DIAMOND_SWORD` or `STONE`. Names are case-insensitive. Entries with an unknown material, or one that cannot exist as an item, are skipped with a console error. **Required.**

## Food Properties

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `nutrition` | whole number, 0 or more | `0` | Hunger points restored. Two points are one drumstick. |
| `saturation` | number, 0 or more | `0` | Saturation restored. Higher values keep the player full for longer. |
| `can-always-eat` | `true` / `false` | `false` | Allows eating on a full hunger bar. Enable it for potions and buffs. |

Negative numbers are raised to `0`.

## Consumption

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `eat-seconds` | number above 0 | `1.6` | How long eating takes. Values of zero or less use `1.6`. |
| `animation` | name | `EAT` | Use animation: `NONE`, `EAT`, `DRINK`, `BLOCK`, `BOW`, `SPEAR`, `CROSSBOW`, `SPYGLASS`, `TOOT_HORN` or `BRUSH`. An unknown name uses `EAT`. |
| `consume-particles` | `true` / `false` | `true` | Crumb or splash particles while eating. |
| `sound` | sound key | empty | Sound played when eating finishes, for example `entity.player.burp`. Empty keeps the material's own eating or drinking sound. An invalid key is ignored. |

The sound takes a vanilla sound event key, or the key of a sound from a resource pack, with or without the `minecraft:` prefix.
