```
[*]The placeholders register automatically when PlaceholderAPI is installed and are refreshed by [icode]/frameui reload[/icode]. Without PlaceholderAPI, nothing changes.
[*]Removed an unused import and an unused lambda parameter in the resource-pack loader.
[/list]
```
